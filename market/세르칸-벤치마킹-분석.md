## 한눈에 — 세르칸은 어떤 계정인가

- **포지션**: "내 외모의 최고 버전이 궁금하다면?" — 남자 외모·자기관리 토탈 큐레이션.
- **슬로건(머리글자 각인)**: SERKAN = **S**tart **E**very **R**outine with **K**een **A**wareness **N**ow.
- **운영 정체성**: faceless 아님(인물·신체 노출 많음). 하지만 **얼굴=특정 1인에 종속되지 않고** 영화 스틸·운동인물·오브제를 폭넓게 씀 → 우리가 배울 건 "사람을 쓰되 특정 인물 브랜드가 안 되는 법".
- **수익 구조**: "(광고X)" 명시 + 타사 제품 큐레이션 + 자기 계정 팔로우 유도. **자사 제품 판매 없음** → 우리 P1 모델과 동일.
- **팔로잉 1**: 철저히 매거진/미디어 포지션(맞팔 안 함)으로 권위 연출.

## 세르칸의 섹션 라벨 체계 (좌상단 영어 라벨 = 카테고리)

세르칸은 모든 게시물 좌상단에 영어 섹션 라벨을 박는다. 이게 곧 그의 콘텐츠 분류 체계다. bodetail의 `label-section`과 동일한 위치·기능.

| 세르칸 라벨 | 의미 | 다루는 내용 |
|---|---|---|
| **Advice** | 조언·태도·마인드셋 | "20대로 돌아가면 반드시 지킬 7가지", "실패를 끝으로 만들지 않는 태도", "유부남의 자기관리 원칙 4", "테스토스테론 높이는 자세 8" |
| **Posture** | 자세·체형 교정 | "5분 스트레칭으로 10년 젊어지기", "수건 하나로 자세교정 시작하기", "사무실에서 자세교정 동작" |
| **Workout Routine** | 운동 루틴 | "가장 효율적인 복근 운동 루틴", "폭발적인 전완근 만들기", "삼두운동 상급자 디테일" |
| **Routine Index** | 루틴 인덱스(종합 가이드) | "하루를 다잡는 작은 디테일 5", "분야를 넘나드는 자기관리", "곱게 나이드는 습관 BEST 8" |
| **Curation** (하이라이트) | 제품 큐레이션 | "마음 먹고 투자할 만한 자기관리템"(향수·다이어리·칫솔 등 7종), "추구미별 남자향수" |

> 하이라이트도 섹션으로 운영: **KANS / TEAM / Curation / 100K / lab / RISE / QNA**. 매거진처럼 코너를 고정 운영.

## 주제 카테고리별 전수 분해 (게시물+릴스 관찰분)

지금까지 캡처에서 확인된 세르칸 콘텐츠를 7개 주제군으로 분류:

### 1. 그루밍·디테일 (← bodetail 핵심 앵커)
- "가장 간단한 헤어 & 그루밍 용어집 上"
- "다시 짚어보는 샴푸의 정석"
- "피부톤별 어울리는 색상표"
- "추구미별 남자향수" / "마음 먹고 투자할 만한 자기관리템"(향수 중심)
- "데이트 직전 ↓ 핸섬해지기"
→ **우리가 가장 깊게 가져갈 영역.** 세르칸은 넓게 훑지만 그루밍 전문 계정은 아님 → 우리는 여기서 더 깊고 감각적으로.

### 2. 운동·신체 (Workout / Posture)
- 복근·전완근·삼두·자세교정·스트레칭 다수
- "근손실 덜 오는 선택들 8", "집요한 반복 압도적 경지"
→ **우리는 보조 영토.** 바디/컨디셔닝 렌즈로만(운동 기록이 아니라 "관리되는 몸"의 디테일). 세르칸만큼 운동 전문으로 안 감.

### 3. 자기관리 마인드셋 (Advice)
- "20대로 돌아가면 지킬 7가지", "실패를 끝으로 만들지 않는 태도", "지쳤다는 신호 10가지", "외모 또한 경쟁력"
→ **헤드라인 공식만 차용**(자기효능 자극형). 우리 voice_guide 공식7에 이미 반영.

### 4. 제품 큐레이션 (Curation)
- "(광고X) 자기관리템" 7종: 전동칫솔/중량조끼/하이엔드 다이어리/홈케어 기기/쿨링 마사저/요가매트/기능성 베개
- 향수·샴푸 등
→ **우리 PICK 섹션의 교본.** "(광고X)" 정직성 + 안목 큐레이션 구조 그대로. P1엔 타사만.

### 5. 영양·컨디션
- "필수영양제 시간대별 총정리 루틴", "취침 전" 루틴
→ 보조. EDC/컨디셔닝과 묶어 가끔.

### 6. 인물·동기부여 레퍼런스
- 영화배우/운동선수 스틸 활용("애런 도널드", 브래드 피트, 호날두 등) — "그들의 지독한 1% 자기관리 루틴"
→ **유명인 루틴을 빌려 권위 연출.** 단 우리는 faceless 원칙이라 인물 정면 사용은 지양 → 오브제·손·뒷모습으로 변환.

### 7. 시즌·트렌드
- "2026 PX 추천 제품 리스트", "여름 선크림" 등 시즌성
→ TREND 섹션으로 가끔.

## bodetail이 가져갈 것 vs 버릴 것

| 항목 | 세르칸 | bodetail 결정 |
|---|---|---|
| 좌상단 영어 섹션 라벨 | Advice/Posture/… | **가져감** — 우리 라벨 체계로(WHY/PICK/오늘의 디테일/그 순간/레퍼런스/TREND) |
| 하단 워드마크 서명 | SERKAN | **가져감** — signature-wordmark로 이미 반영 |
| 2단 헤드라인+화살표 | "데이트 직전 ↓ 핸섬해지기" | **가져감** — headline-block-tiered |
| 넘버링 박스(+02) | 큰 숫자 | **가져감** — number-box |
| "(광고X)" 정직성 | 캡션 첫 줄 | **가져감** — voice_guide 반영됨 |
| 머리글자 슬로건 | SERKAN 각인 | **가져감(미정)** — bodetail 버전 제작 필요 |
| 인물 정면·신체 노출 | 많음 | **버림** — faceless 유지. 오브제·손·질감·뒷모습으로 |
| 운동 전문성 | 깊음 | **버림(약하게만)** — 그루밍/감도로 차별화 |
| 붉은/브라운 톤 | 시그니처 | **버림** — 우리는 잉크블랙+골드 |
| 영화 스틸 직접 사용 | 잦음 | **주의** — 저작권/톤 리스크. 자체 생성 오브제로 |

## 차별화 한 줄

세르칸 = **넓게(외모 전반) · 사람 중심 · 붉은 시네마틱 · 자기계발 톤**.
bodetail = **깊게(그루밍·디테일) · 오브제 중심(faceless) · 잉크블랙 골드 · 무드매거진 톤**.
→ 같은 독자(자기관리하는 남자)를 노리되, 세르칸이 "동기부여 코치"라면 우리는 "안목 있는 에디터".

## 추가로 있으면 좋을 자료

- 세르칸 **릴스 탭** 상위 10개 제목/주제(현재 릴스는 그리드 제목만 확인됨 — 영상 훅·구성은 미관찰).
- "(광고)" 표기된 실제 협찬 게시물 1~2건(협찬을 어떻게 매거진 톤으로 녹이는지).
- 우리와 더 가까운 **faceless 그루밍 계정**(세르칸은 인물 중심이라 faceless 실행 예시는 아직 없음).

## [추가] 전체 콘텐츠 라이브러리 전수 분석 (약 100개 게시물 관찰)

표지 몇 장이 아니라 그리드 전체를 보니 주제 무게중심이 명확해졌다.

**빈도순 주제 분포:**
1. **스킨케어·피부** (최다) — 성분 용어집 上中下, 레티놀, 피부타입 판단, 효능별 화장품 5선, 피부과 가성비시술. → **우리 그루밍 앵커와 정면으로 겹침.**
2. **그루밍·면도·향수** — 면도날, 구취제거, 남자향수, 눈썹정리, 탈모예방.
3. **자기관리 마인드셋** — 위대함을 향한 여정, 미의 기준, 외모=경쟁력.
4. **운동·신체** — 복근/전완근/자세교정.
5. **제품 큐레이션** — 자기관리템, 주머니 속 아이템.
6. **영양·수면·컨디션** — 영양제 타이밍, 발마사지, 비타민D.
7. **헤어·두피 / 시즌·밈** — 두피관리, 연말 질문리스트, 유명인 루틴.

→ **결정적 함의**: 세르칸의 무게중심은 운동이 아니라 **스킨케어·그루밍·피부**다. 우리와 앵커가 거의 같다. "같은 주제, 다른 인격(faceless 무드매거진)"으로의 차별화가 생존 전략.

## [추가] 릴스 조회수 = 바이럴 실측 데이터

릴스 썸네일엔 조회수가 노출된다. 이게 "뭐가 터지나"의 실측이다.

**최상위 (80만~230만):**
- 삼두운동 상급자 디테일 **230만**
- 관리의 효과를 체감할 것 **152만**
- 데이트 전 외모개선 루틴 **147만**
- 유부남의 자기관리 원칙 4 **90만**
- 구부정한 자세 교정 가이드 **87만**
- 힘 들이지 않고 곧은 자세로 앉기 **84만**
- 자기관리가 가장 필요한 9개월 **84만**

**중상위 (30만~40만):** 퍼스널컬러 찾기, 가짜 배 집어넣기, 병오년 숨 고르기, 체지방률 외모변화, 인생 바꾼 마인드셋 3가지, 팔 아래 깔끔하게, 체지방10% 아침식단.

**바이럴 패턴 3:**
1. **"즉효·디테일" 후킹이 최상위** — 작은 디테일로 큰 변화 약속(230만/152만). bodetail 브랜드 코어와 일치.
2. **즉시 실행형 > 추상 동기부여** — 자세교정(84만) > 마인드셋(32만).
3. **시의성** — 연초·시즌 타이밍 후킹이 잘 먹힘.

→ voice_guide.md "후킹 우선순위" 섹션에 반영 완료.

## [추가] 사진 소싱 — 우리의 결정적 차별점

세르칸은 헐리웃 배우·영화 스틸·운동선수 사진을 쓴다(저작권 회색지대, 무단). 계정이 커지고 수익화할수록 리스크가 커지는 구조. **bodetail은 이 길을 안 간다:**

- **고정 마스코트**(자체 IP) + AI 오브제·손 클로즈업 + 라이선스 클리어 스톡.
- faceless가 약점이 아니라 **강점**: 세르칸은 매번 "쓸 만한 인물 사진"을 찾아야 하지만, 우리는 마스코트·오브제라 무한 생성 가능 + 저작권 0 리스크 + 매번 같은 캐릭터라 친근감 누적.
- 세르칸엔 없는 우리만의 무기 = **브랜드 마스코트의 시리즈 정체성.**

→ 디자인 MD "사진 소싱 로직" + "마스코트 시스템" 섹션에 반영 완료.
