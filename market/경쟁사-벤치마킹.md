# 경쟁사 벤치마킹

## BFRB·손톱 케어 시장 규모
- BFRB(손톱 물어뜯기) 국내 인구: **약 250만 명**
- 손톱 뜯는 인구 전체: **700만~1,000만 명**
- 직접 경쟁자: 사실상 없음 → **블루오션**
- 우리 5년 목표: **13.5만 병** (토리든 누적 판매의 약 1% — 현실적이지만 까다로운 목표)

## 한눈에 비교

| 구분 | 토리든 | 셀리맥스 | 마미케어 | 코골이 테이프 | 우리(손톱) |
|------|--------|---------|---------|------------|----------|
| 히어로 상품 | 다이브인 세럼 | 레티날 세럼 | 바다포도 앰플 | 입막음 테이프 | 손톱 케어 세럼 |
| 핵심 무기 | 저자극·후기 | 성분 1위·글로벌 | 성분 네이밍·광고 | 충격 비주얼 | 살롱·서사·블루오션 |
| 성장 동력 | 오가닉 | 플랫폼 1위 | 유료광고 | 유료광고 | **오가닉 지향** |

## 토리든 — 롤모델 ★★★

| 지표 | 수치 |
|------|------|
| 2024 매출 | **₩1,860억** (전년 673억 → +176%) |
| 영업이익률 | **28%** (업계 최상위) |
| 누적 판매 | **1,361만 병** (단일 제품이 브랜드 메가화) |

**성공 공식**
- 오랫동안 무명 → 2022년 클린뷰티 트렌드에 맞춰 용기·라벨 투명하게 교체
- 화해(앱)에서 선판매로 후기 먼저 쌓음 → "촉촉하고 순한 세럼" 오가닉 입소문
- 출시 2년 만에 매출 2억→17억

**우리 벤치마크**
① 저자극·순함을 핵심 메시지로 ② 후기를 먼저 쌓고 시작 ③ 단일 제품 집중 ④ 2년의 빌드업

> 교훈: 토리든의 진짜 무기는 "광고를 잘 산 것"이 아니라 **"후기로 광고비 없이 팔리는 구조"**.

## 셀리맥스 — 단일 성분 1위 전략 ★★

| 지표 | 수치 |
|------|------|
| 매출 성장 | ₩462억 → ₩1,700억 (1년 만에 3.7배, 70여 개국) |
| 핵심 | 아마존 레티날 카테고리 1위 |
| 유통 | 미국 얼타 1,300개 전 매장 |

**우리 벤치마크**: 하나의 성분/제품으로 한 카테고리 장악 → "손톱 케어" 카테고리 1등 전략.

## 셀라딕스=㈜이삼오구(2359) — 반면교사 ❌

| 연도 | 매출 |
|------|------|
| 2021 | 230억 |
| 2022 | 600억 (+240%) |
| 2024 | 1,294억 |
| 2023 영업이익 | 45.3억 (-42%) |

- **매출↑ 이익↓ = 유료광고 의존 D2C 함정**
- 이익률 4~6% (토리든 28%의 1/6)
- **교훈: 광고물량 모델은 자본 싸움 — 절대 따라가지 말 것. 토리든식 오가닉+재구매로.**

## 마미케어 — 기법만 차용 ★

- 바다포도 앰플: SNS 대란 → 올리브영 품절템 (누적 100만 병)
- 가격: 정가 ₩4.9만 / 1+1·사은품 프로모션
- **배울 점**: 기억에 남는 성분 네이밍(바다포도), 번들·사은품으로 객단가 상승
- **피할 점**: "모공 150% 개선" 과장 임상, 효과 논란, 광고·프로모션 의존(해자 없음)

## 코골이/입막음 테이프 — 반면교사 ❌

- 충격 비주얼 → 틱톡 5,200만 조회 폭발적 바이럴
- 다수 브랜드 난립 (바른수면밴드 1,400만 매 등)
- **해자 없음** — 진입장벽 0, 가격·광고 싸움, 브랜드 안 남음
- 의사들 효과·안전 경고

> 핵심 교훈: **"코골이 테이프의 바이럴 + 토리든의 해자·신뢰"** = 우리 목표. 바이럴만 → 반짝 사라짐, 해자만 → 안 알려짐. 둘 다 필요.

## ROAS 분석

| 구분 | 추정 ROAS | 근거 |
|------|---------|------|
| 업계 평균 (유료광고) | Meta ~1.5 / 틱톡 ~1.6 | 화장품 이커머스 벤치마크 |
| 토리든 | 실질 高 (오가닉) | 영업이익률 28% = 광고 없이 팔림 |
| 마미케어·코골이 | 中 (1.5~3, 유료 의존) | 광고·프로모션 미는 구조 |
| **우리 지향** | **오가닉 高 목표** | 창업자 서사·비포애프터로 유기 도달 |

## 매각 멀티플 (K-뷰티 M&A)

| 사례 | EV/EBITDA |
|------|-----------|
| 스킨푸드 (구다이글로벌) | 9배 |
| 서린컴퍼니 | 약 7배 |
| 스킨이데아 (모건스탠리PE) | 약 6배 |

- **K뷰티 기준**: 성장성·독창성 강하면 9배, 올드하면 6배
- **우리 시나리오** (영업이익 10억 달성 시): **₩60~90억**
- 멀티플 결정 요소: **3~5년 우상향 + 재구매율(LTV)** — 단발 이익엔 멀티플 안 쳐줌

## 재무 기준
- K뷰티 EV/EBITDA: **6~9배**
- 지분 전략: 검증 전 자력(예창패) → 검증 후 투자
- "지분% 아닌 지분×회사가치" 절대값으로 사고

## 우리의 경쟁 위치

| 우리가 이기는 것 | 우리가 불리한 것 |
|---------------|--------------|
| 경쟁 없음 (블루오션) | 효과 객관적 입증 어려움 (자체 임상 불가) |
| 페인 절박도 높음 (컴플렉스) | 효과 체감 느림 → 초반 이탈 위험 |
| 해자: 살롱 origin + 창업자 서사 | 초기 인지·노출 어려움 (숨기는 페인) |
| 재구매 잠재력 (긴 케어 기간) | 시장 크기 자체는 틈새 |
| 남녀공용 시장 | |

> 최종 진단: 약점(효과 입증·노출)을 **창업자 서사 + 비포애프터 + 후기**로 메우면, 강점(블루오션·해자·재구매)이 살아나 토리든 성공 공식을 더 적은 경쟁으로 달성 가능.
