# 오브제(OBgE) 마케팅 벤치마킹 분석

> 운영사: 어댑트(ADAPT) / D2C 미디어커머스 / 2017 설립
> 매출: 2021년 488억 → 2024년 약 2,000억 / 2025년 목표 3,000억
> 오브제 단독: 2023년 올리브영 연매출 100억 돌파

## 핵심 성공 공식 7가지

### 1. "화장"이라는 단어를 철저히 배제
- 박정하 대표: 제품 기획~마케팅까지 "화장" 단어 안 씀
- "화장하는 남성" 이미지 = 남성 시장 거부감 유발
- → 바디테일 적용: "케어·정돈·디테일"만. "화장·뷰티·메이크업" 금지

### 2. "거부감 제거"를 제품 설계의 1순위로
- 톤커버 로션: 인위적 톤보정 거부감을 보완, 로션 대용으로 사용
- 진입장벽(거부감)을 낮춰 입문자 흡수
- → 바디테일 적용: 롤온=메니큐어 거부감 제거. "그냥 슥" 포지션

### 3. "한 끗" 슬로건
- 오브제: "티 나지 않고 자연스럽게, 한 끗 다른 스타일의 완성"
- → 바디테일: "남들이 지나치는 한 끗" — 이미 같은 키워드 사용 중. 검증됨

### 4. 단일 히트 제품으로 카테고리 장악 후 확장
- 내추럴 커버 파운데이션(400만개) → 스킨케어(포어 제로) → 선케어 순차 확장
- 하나로 신뢰 쌓고 라인 넓히는 전략
- → 바디테일 적용: 손톱 오일(EP1)로 시작 → 큐티클·입술·발 세계관 확장

### 5. 콘텐츠-판매 일체형 (미디어커머스)
- "기획-콘텐츠-판매가 하나로 연결된 브랜드 경험"
- 콘텐츠가 곧 판매 채널
- → 바디테일 적용: 릴스 오가닉 → 콘텐츠 자체가 유입·전환 동력

### 6. 채널 단계적 확장
- 자사몰 → 올리브영(오프라인 신뢰) → 쿠팡/무신사 → 아마존재팬·대만 쇼피
- → 바디테일 적용: 인스타 → D2C → 올리브영(선택) → 벤더 직수출

### 7. 어워즈/수상 이력 적극 활용
- 올리브영·쿠팡·무신사 어워즈 수상을 신뢰 마케팅에 활용
- → 바디테일 적용: 초기엔 "리버니 네일샵이 만든" 전문성으로 대체

## 바디테일이 더 유리한 점
- 오브제=얼굴(레드오션 진입) / 바디테일=손끝(블루오션)
- 오브제 영업이익률 약 7% (광고비 부담) / 바디테일=오가닉으로 마진 우위
- "오브제 쓰는 남자가 다음에 챙길 디테일"로 비충돌 포지션 가능

## 경계할 점
- 어댑트는 미디어커머스라 광고비 대량 투입 모델 → 우리는 오가닉 고수
- 멀티플보다 영업이익 절댓값이 기업가치 핵심
- 오가닉 마진 우위가 향후 밸류에이션의 최대 무기
