# 주요 의사결정 기록

## ✅ 제형: 무수 오일로 결정
- **결정**: 무수(無水) 드라이 오일 베이스
- **이유**: 희망 성분이 수상+유상 혼재 → 물 들어가면 방부 필수. 무수면 방부 불필요·저자극.
- **출처**: 라온하제 제안 수용 (2026-06-17)

## ✅ 용기: 롤온 1순위, 펜팁 2순위
- **결정**: 롤온(롤러볼) 1순위 / 형광펜식 단단한 팁 2순위
- **이유**: 손톱·큐티클 조준 도포 + 마사지감. 스프레이는 조준·점도·마사지 모두 불리.
- **남성 배려**: 매니큐어 붓에 거부감 → 도포구 형태만 변경

## ✅ "회복" 표현도 빼기
- **결정**: "회복" 용어 사용 금지
- **이유**: 화장품법상 "회복"이 손상 되돌림 = 의약품적 효능으로 해석 위험 (라온하제 지적)
- **대체 표현**: 보습, 관리, 정돈, 영양, 케어

## ✅ 1순위 OEM = 라온하제 20ml 1,500개 (잠정)
- **결정**: 라온하제, 20ml 롤온, 초도 1,500개 (잠정)
- **이유**: 롤온 충진 일괄 확답 + MOQ 최소(1,500개) + 재고 리스크 절반
- **조건**: 단가·소비자가·수요검증 미확정 → **양산 결정 보류, 샘플 먼저**

## ✅ 핵심 전략: 토리든식 오가닉+재구매 (셀라딕스식 광고물량 X)
- **결정**: 유료광고 물량 모델 거부 → 오가닉 + 재구매 구조
- **이유**: 광고물량은 자본 싸움 — 대기업을 이길 수 없음
- **실행 순서**: 수요 검증(인스타 반응) 먼저, 양산은 그 후
- **반복 경고**: "만들기 과몰입, 팔기 검증 0" → 에너지를 수요 검증에 집중

## ✅ 도구: Claude Code 단일 → 나중에 Ollama 하이브리드
- **결정**: 지금은 Claude Code(Sonnet) 단일 운영
- **이유**: 검증 전엔 단순함 > 비용절감. 대량 자동화 시 Ollama로 반복 작업 분리
- **타임라인**: 팔로워 1,000명+ / 콘텐츠 50개+ 이후 하이브리드 고려
- **안티그래비티**: Ollama 하이브리드 단계에서 활용 (지금 부적합)
- **Opus/Fable 필요한 시점**: 수백 파일 대형 리팩토링, 장기 자율 에이전트, 수십 문서 교차 추론 — 현재는 Sonnet으로 충분

## ✅ 세컨드 브레인: 콘텐츠 볼트 + LLM 위키 볼트 분리
- **결정**: 볼트 2개 분리 운영
- **이유**: 이질적 자료를 한 볼트에 섞으면 컨텍스트 오염
- **역할 분담**: 위키 = 사업 두뇌(지식), 콘텐츠 볼트 = 공장. 보완 관계.
- **현재 완성도**: 약 60% — 5대 보완 계획·메타 API 연동 계획은 [[decisions/콘텐츠-볼트-운영]] 참조

## ✅ 법인 구조: 단계적 하이브리드
- **1단계 (검증기, ~전역 직후)**: 리버니 브랜드로 출발 — "리버니가 만든 제품" 신뢰 직결
- **2단계 (성장기)**: 제품 브랜드를 별도 법인으로 분사 → 리스크 분리 + 투자 유치
- **예창패 자격 노린다면**: 신규 제품사만 신규 사업자로 분리 + 리버니와 협업 계약 (신뢰 vs 지원 자격 트레이드오프 판단 필요)

| **청년창업사관학교** | 만 39세 이하, 3년 이내 | 최대 1억 + 공간·교육·코칭 | 2순위 |

## 📋 5년 재무 목표

| 시나리오 | 5년차 | 확률 |
|---------|------|------|
| 성공 (상위) | 매출 **70억**, 영업이익 **12.5억**, 밸류 **60~90억** | 상위 10~20% |
| 중간 안착 | 매출 10~20억 · 생활 가능한 1인 브랜드 | **현실적 목표** |
| 조기 정체 | 2년차 점프 실패 → 소규모·부업 수준 | 흔한 결과 |

> **중간만 가도 성공이다.** 재구매 도는 단단한 브랜드를 1순위 목표로. 중간에 멈춰도 수십억 자산·경험·데이터가 남는다.

## ⚠️ 리스크 · 실패 대비

| 리스크 | 현실 | 대응 |
|--------|------|------|
| 도달 실패 | 손톱은 숨기는 페인 → 노출이 안 터질 수 있음 | 변수 실험으로 훅 탐색 / 여성 여론 활용 / 광고 소액 테스트 |
| 재구매 안 됨 | 효과 체감 느려 초반 이탈 → 1년차 핵심 지표 붕괴 | 21일 챌린지·습관화 / 빠른 체감(거스러미·보습) 전면 / 제형·메시지 피벗 |
| 후발주자 모방 | 시장 열면 대기업·경쟁사 베낌 | 1사1처방 독점 / 살롱 origin / 선점 브랜드 인지 / 에피소드 세계관 |
| 예창패 탈락 | 합격률 25~40% | A안(자비·융자 소규모 런칭)으로 전환 / 다음 차수 재도전 / 콘텐츠는 계속 |
| 효과 논란 | 과장 광고 시 마미케어처럼 역풍 | "치료·완치" 금지 철저 / "개인차 있음" 명시 / 정직한 후기만 |

### 언제 피벗하고 언제 접나 (기준)

| 시점 | 점검 항목 | 판단 |
|------|---------|------|

| 1년차 말 | 매출·재구매 둘 다 | 신통찮으면 → 살롱 부가 판매로만 / 정리. **손실 한도를 시작 전에 숫자로 정해둘 것** |

## ⚠️ 절대 하지 말 것 (반복 경고)
- 영양제(건기식)는 화장품 아님 — **1차 라인업에서 완전 제외**
- 곁가지 확장 경계 (블랭크 교훈) — 네일 케어 한 축에 집중
- 컬러 폴리시 등 SKU 남발 — 재고·MOQ 함정
- 단발 히트 의존 — 소모품 재구매 구조로 설계
- 자체 임상은 지원 선정 후 지원금으로 — 지금은 창업자 서사·비포애프터·후기
