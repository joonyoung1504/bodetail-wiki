# 상표 · 임상 · 예창패 준비

## 상표 출원 — 지금 바로

특허(신규성·진보성 통과 어려움)보다 **상표**가 현실적. 선출원주의라 빠를수록 유리.

| 항목 | 내용 |
|------|------|
| 출원 대상 | 리버니/LIBUNNY + 바디테일/bodetail (한글·영문) |
| 분류 | **제3류 (화장품) + 제44류 (네일서비스)** |
| 준비물 | ① 키프리스(kipris.or.kr) 선행검색 ② 로고 PNG(배경 없는 버전) ③ 출원 대상 목록 |
| 방법 | 변리사 (1건 30~70만원, 거절 대응 안전) 또는 특허로(patent.go.kr, 6~12만원 직접) |
| 예창패 영향 | 없음. 출원증 = **가점·실행력 증거** |

나중에 고려할 것(지금 아님):
- 디자인 등록: 용기 확정 후
- 실용신안: 노크식 롤러볼 구조

## 임상 전략 — 후기가 먼저, 임상은 나중

| 구분 | 살롱 고객 체험 | 자체 임상(CRO) |
|------|--------------|--------------|
| 누가 | 살롱 고객 | 전문 시험기관 |
| 결과물 | 후기·비포애프터 | 시험성적서(공인) |
| 광고 효력 | "후기"로만 | "○% 개선" 수치 가능 |
| 비용 | 0원 | 수백만~수천만 |

> **주의**: 살롱 체험 ≠ 임상. 측정·통제가 없어 "임상 입증·OO% 개선·치료" 표현 쓰면 과장광고(화장품법 위반).  
> **단, "실사용 후기·비포애프터"로는 합법적이고 강력** ("개인차 있음" 명시 필수).

**1년차엔 후기 > 임상.** 사람들은 "임상 30%"보다 "나 같은 사람이 4주 만에 이렇게"에 반응. 토리든도 후기로 떴다.

CRO 업체 (나중 단계): **더마프로·피앤케이·KCL** — 예창패 선정 후 지원금으로 진행이 좋은 계획.

## 예창패 준비 — B안 추천

### 자격·일정

- 자격: 공고일 기준 본인 명의 사업자/법인 없으면 OK
- 리버니 = 누나 소유 → 준영 자격에 무관 (협업 구조로 오히려 깔끔)
- **다음 본차수: 2027년 2~3월 정조준** (12월 통합공고로 라인업 확정)
- 지원금: 평균 5,000만원 (최대 1억) — **지분·상환·이자 없는 보조금**
- 바우처 집행: 공장 세금계산서 → 정부가 공장에 직접 지급 (현금 X)
- 단, 대표·가족 인건비 불가 → 생계비는 별도

### A안 vs B안

| | A안 | **B안 (추천)** |
|--|-----|-------------|
| 전략 | 8월 자비·융자로 바로 런칭 | 등록·발주만 지원금 시점에 맞추고, 나머지는 다 준비 → 2027 지원 |
| 장점 | 빠른 검증 | A의 상위호환. 떨어져도 A로 전환 가능 |
| 특이사항 | 예창패 자격 포기 | 어차피 9월 전역. 준비는 등록 없이 다 가능 |

### 지원 전 준비 6대 카테고리

| 카테고리 | 할 일 |
|---------|------|
| ① 법적·행정 | 상표 출원 / 책임판매관리자 자격 확인 / 도메인·핸들 선점 |
| ② 창업교육 | K-Startup·소상공인 지식배움터·중기부 온라인 무료 → 이수증 3개 목표 (가점) |
| ③ 콘텐츠·검증 | 인스타 6~9개월 운영(팔로워 1,000+·저장률 4%+) / 사전수요 설문 / 손톱 비포 기록 |
| ④ 제품 | 공장→샘플→매장 테스트 / 디자인 완성 (등록 없이 가능) |
| ⑤ 사업계획서 | PSST 완성 / 개요 1p 강화 / 데이터 채우기 / 발표 PPT |
| ⑥ 스킬 | 25시간 스프린트 / AI 마케팅 / 스마트스토어 셋업 |

**합격률 가르는 top 3**: ① 샘플 실물 (아이디어 vs 실물은 차원이 다름) ② 인스타 반응 데이터 ③ 개요 1페이지

### 창업교육 이수법

- 소요: 과정당 2~4시간. 군 복무 중 온라인 가능
- k-startup.go.kr 가입 → 창업교육 → 무료 수강 → 이수증 PDF 다운로드 → 보관
- 여러 개 들을수록 가점 유리

## 기타 행정

- **책임판매관리자 자격**: 지방식약청에 미리 확인 (안 되면 교육 수강)
- **도메인·핸들 선점**: bodetail.com, 인스타·틱톡·유튜브 @bodetail
- **약국 공급**: 신뢰 프리미엄 있지만 마진 감소. D2C 자리잡은 뒤 검토.
