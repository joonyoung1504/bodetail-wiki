## 2. 로고 / 워드마크

- 소문자 산세리프 `bodetail`, 굵은 웨이트
- 크랙(균열) / 텍스처 처리 → 빈티지·강인한 인상
- 색: 웜 크림(`#EDE2D0`) + 골드 외곽선
- 워드마크 아래 골드 hairline + 태그라인 골드 올캡

## 5. 디자인 무드
- 거친 그런지·페인트 스플래터·크랙 텍스처
- 블랙 위 골드 = 프리미엄 + 강인함
- 노기어식 "강렬한 인트로" 레퍼런스
- 고급 남성 그루밍 타깃에 맞는 무게감

## ⚠️ 기존 아이덴티티와의 충돌 — 의사결정 필요

기존 확정 팔레트(`decisions/브랜드-포지셔닝-결정`)와 이번 첫 게시물의 **배경색이 다름.**

| 항목 | 기존 확정 | 이번 게시물 세트 |
|---|---|---|
| 메인 배경 | 옥스블러드 `#6B1620` / 포슬린 `#F2ECE6` | **블랙 `#0C0C0C`** |
| 포인트 | 골드 `#B0844A` | 골드 `#B0844A` ✅ 동일 |
| 본문 | 포슬린 `#F2ECE6` | 웜 크림 `#EDE2D0` (유사) |
| 헤드라인 폰트 | Fraunces (세리프) | 콘덴스드 산세리프 |

**결정할 것:**
1. **옥스블러드 베이스** (우아·프리미엄, 기존 확정) 유지
2. **블랙+골드 베이스** (강렬·스트릿, 이번 세트) 로 전환
3. **용도 분리**: 제품/패키지 = 옥스블러드, SNS 인트로 = 블랙
