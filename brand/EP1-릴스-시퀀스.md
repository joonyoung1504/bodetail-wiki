# EP1 릴스 시퀀스 & 변수 실험 매트릭스

## EP1 논리 사슬 8단계

설득 구조: "큰 공감대 → 좁혀들어가기 → 우리 문제로 착지 → 해결 제시"의 깔때기.  
특히 "단점 없음 → 깔끔함 → 디테일 → 손톱"으로 좁히는 흐름이 핵심.

| # | 메시지 | 릴스 역할 |
|---|--------|---------|
| 1 | 여자는 장점 뚜렷한 남자보다 **단점 없는 남자**를 좋아한다 | 넓은 공감 훅 — 누구나 클릭 |
| 2 | 외모에서 단점 없음 = **깔끔함**으로 인식된다 | 개념 좁히기 |
| 3 | 깔끔하려면 **사소한 디테일**이 차별화의 핵심 | 브랜드 세계관(바디테일) 연결 |
| 4 | 길거리 밸런스 투표 → **손톱을 의외로 많이 본다** | 증명·반전 (저장·공유 터짐) |
| 5 | 볼 때 — 깨짐·물어뜯음·때낌·갈라짐·변형을 **싫어한다** | 페인 자각 |
| 6 | 컴플렉스 가진 **남자들 많다** | "저요" 공감·고백 유도 |
| 7 | 제품 비포애프터 → **2.5만원으로 다시 자신 있게** | 해결 제시·전환 |
| 8 | 성분 순해 변형·갈라짐·때 개선 + 습관 교정 / 안 뜯어도 **롤러볼 휴대 = 호감포인트** | 제품 가치·확장 수요 |

> 카피 교정: "평생 고친다·치료·습관을 고친다" → 화장품법 위반.  
> → "다시 자신 있게", "습관을 바꾸는 90일", "관리하다"로.

## EP1 발행 전략 — 잠금·리빌

EP1이 충분히 터진 뒤(저장률·팔로워 목표) → EP2 공개. 넷플릭스 시즌 구조.  
**터지기 전에 다음 에피소드 열면 분산 → 블랭크 함정.**

```
EP1 손톱 🔓 지금  →  EP2 큐티클·손 🔒  →  EP3 입술 🔒  →  EP4 발 🔒
```

8단계 각각을 아래 변수 매트릭스로 여러 버전 제작 → 수십~수백 개 실험 풀.

## 변수 실험 매트릭스 (T1~T4)

큰 변수(T1)부터 실험. 자리잡은 뒤 T4 미세 최적화. 큰 변수가 반응의 80% 좌우.

| 티어 | 변수 | 경우의 수 |
|------|------|---------|
| **T1 · 주제(Topic)** | 어떤 페인을 다루나 | 물어뜯기 / 셀프젤손상 / 거스러미 / 때낌 / 갈라짐 / 호감포인트 |
| **T1 · 훅(Hook)** | 첫 3초 한 줄 | 충격질문 / 공감고백 / 통계제시 / 반전 / 길거리투표 |
| T2 · 포맷(Format) | 영상 구성 | 비포애프터 / 길거리투표 / 토킹헤드 / 타임랩스 / 밈 |
| T2 · 길이 | 러닝타임 | 7초 / 15초 / 25초 / 40초 |
| T2 · 후킹 방식 | 오프닝 화면 | 얼굴먼저 / 손톱클로즈업먼저 / 텍스트먼저 / 결과스포 |
| T3 · 자막 위치 | 텍스트 배치 | 상단 / 중앙 / 하단 |
| T3 · 자막 스타일 | 폰트·크기·색 | 세리프/산세리프 · 대/소 · 흰/옥스블러드/골드 |
| T3 · BGM | 음악 무드 | 잔잔 / 트렌디 / 무음+자막 / ASMR |
| T4 · CTA | 마무리 행동유도 | 21일챌린지 / 대기자폼 / 댓글유도 / 저장유도 / 팔로우 |
| T4 · 발행 시각 | 업로드 타이밍 | 오전7 / 점심12 / 저녁8 / 밤11 |
| T4 · 첫 댓글 | 고정 댓글 | 질문 / 링크 / 공감 / 없음 |
| T4 · 썸네일 프레임 | 커버 이미지 | 비포 / 애프터 / 텍스트 / 제품 |

### 실험 진행 순서 (한 변수씩)

1. **T1 주제 5종 고정 포맷으로 발행** — 어떤 페인이 가장 반응 좋은지 먼저 파악
2. **이긴 주제로 훅 5종 실험** — 같은 주제, 다른 첫 3초
3. **이긴 훅으로 포맷·길이 실험** — 비포애프터 vs 투표, 15초 vs 25초
4. **자막·BGM·CTA·시각 미세 최적화** — 큰 게 정해진 뒤 마지막 1%

> 함정: 한 번에 여러 변수를 바꾸면 "뭐 때문에 터졌는지" 인과 분리 실패.  
> **영상당 변수 하나만.** 나머지는 고정.

## 비포애프터 영상 아이디어

| 아이디어 | 구성 | 노리는 반응 |
|---------|------|----------|
| 창업자 21일 기록 | 준영 본인 손톱 비포 → 매일 1초 타임랩스 → 애프터 | 체류·완주 (끝까지 봐야 결과), 신뢰 |
| 고객 비포애프터 | 살롱 고객 손 변화 + 한 줄 후기 | 공감·전환 ("나도 될까") |
| 스플릿 화면 | 왼쪽 비포 / 오른쪽 애프터 동시 | 즉각 대비·저장 |
| 거스러미·때 클로즈업 | 주변 살 정돈·매끈해짐 디테일 | 빠른 체감 강조 (며칠 내 변화) |
| 롤러볼 휴대 데모 | 주머니서 꺼내 바르는 일상 컷 | "호감포인트"·비BFRB 수요층 |

비포애프터가 강한 이유: "임상 30%"보다 "나 같은 사람이 4주 만에 이렇게"에 반응.  
**"개인차 있음" 명시 필수.**

## 핵심 카피

**앵커 카피**: "2.5만원으로 다시 자신 있게"  
- 질문형: "평생 숨기던 손톱을 2.5만원으로 바꿀 수 있다면?" → 댓글·저장 유도
- "치료·고친다" 대신 → "다시 자신 있게", "이참에 바꿔보세요"

**홍보 앵글**: "진짜 네일샵 사장이 만들었다"  
- 모든 홍보에 "실제 운영 중인 리버니 네일샵 사장이 만든" origin 박기
- 이게 마케터 제품과 못 베끼는 차별점 (4겹 해자 Layer 1)

**'때 덜 낌' 소재** (샘플 실확인 후 콘텐츠화):
- 가능성 있음 (매끈한 표면일수록 이물질 덜 낌)
- 표현: "때가 안 낀다"(단정) X → **"매끈해져 관리가 수월해진다"** O
- 검증되면 BFRB 아닌 수요층까지 확장 가능 — "물어뜯기 안 하는 사람도 쓰는 이유"
