# 타깃 페르소나

> 바디테일은 **남성 블루오션**에서 시작한다. 남성이 메인 타깃인 손톱 케어 제품은 국내에 사실상 없음.

## 메인 페르소나 — 20~30대 남성 (블루오션)

| 항목 | 내용 |
|------|------|
| 연령 | 20~35세 남성 |
| 핵심 문제 | BFRB (손톱·큐티클 물어뜯기·뜯기 습관) / 손톱 컴플렉스 |
| 동기 | 자기관리를 시작하고 싶지만 "어디서부터 시작할지 모르는" 상태 |
| 욕구 | "단점 없는 남자"로 보이고 싶다. 깔끔하게 보이고 싶다. |
| 거부감 | 매니큐어 붓처럼 생긴 도포구 → **롤러볼로 해결** |
| 구매 방식 | 인스타 저장 → 링크 클릭 → 자사몰·스마트스토어 직구매 |

### BFRB 규모

- 손톱 물어뜯기 당사자: 국내 **약 250만 명**
- 손톱 관련 컴플렉스 (뜯기·갈라짐·거스러미 등): **700만~1,000만 명**
- 경쟁 제품: 사실상 없음 → **블루오션**

### 핵심 페인 포인트

1. 갈라지고 깨진 손톱
2. 큐티클 물어뜯기·거스러미
3. 손톱 주변 때 낌
4. "손톱은 숨기고 싶지만 매니큐어는 바르기 싫다"
5. 컴플렉스인데 해결책을 몰랐음

### 콘텐츠 접점

- 인스타그램 릴스 → 저장·공유
- "길거리 투표" 포맷 ("손톱 보는지 안 보는지" — 반전 반응 기대)
- 비포애프터 공감 ("나 같은 사람도 되네")

## 세컨더리 페르소나 — 20~30대 여성 (구매결정자·여론형성자)

| 항목 | 내용 |
|------|------|
| 연령 | 20~35세 여성 |
| 역할 | 남성 타깃의 구매를 이끌거나 직접 선물 |
| 심리 | "내 남자친구가 이런 거 쓰면 좋겠다" |
| 행동 | SNS 공유, 구전 확산, 선물 구매, 본인 사용 (남녀공용) |

> 여성은 **여론형성자**. 메인 콘텐츠는 남성을 노리되, 여성이 "내 남친한테 보내기"를 유도하는 포맷도 유효.

## 포지셔닝 원칙

> "간판은 넓게(디테일 케어 전체), 첫 화살은 손톱 하나로."

무명 계정이 처음부터 넓게 흩뿌리면 아무도 기억 못 함.  
**EP1(손톱)으로 먼저 각인 → 신뢰·재구매 증명 → EP2~4 확장 선언.**

### EP 시리즈 확장 경로

| EP | 타깃 부위 | 상태 |
|----|---------|------|
| EP1 | 손톱 | 지금 |
| EP2 | 큐티클·손 | EP1 터진 뒤 리빌 |
| EP3 | 입술 | 리빌 예정 |
| EP4 | 발 | 리빌 예정 |

### 장기 포지셔닝

**"바디테일 = 관리 잘된 남자의 디테일 케어 필수 브랜드."**  
향수·헤어처럼 "느좋(느낌 좋은) 남자라면 당연히 챙기는" 카테고리로 자리매김.  
남성 그루밍 시장에서 **손톱·디테일은 아직 비어있다.**
