# 브랜드 정체성 — 바디테일 (bodetail)

## 브랜드 구조
- 브랜드명: **바디테일 (bodetail)** = body + detail
- 슬로건 방향: "놓치기 쉬운 디테일을 돌본다" (손→큐티클→입술→발 확장 가능한 세계관)
- 인스타 핸들: @bodetail (예정)
- 사업자: 리버니 네일케어
- 스토리라인: "리버니가 만든 바디테일"

## 포지셔닝 원칙
> 간판은 넓게(디테일 케어 전체), 첫 화살은 손톱 하나로.

무명 계정이 넓게 흩뿌리면 아무도 기억 못 함 — "손톱 뜯는 습관"이라는 뾰족한 페인으로 먼저 꽂고, 모인 사람에게 브랜드 세계관을 천천히 보여줌.

## 타깃 페르소나

### 메인 — 20~30대 남성 (블루오션)
- BFRB(손톱 물어뜯기) 당사자
- 자기관리 시작하는 남성, "관리하고 싶지만 어디서부터 시작할지 모르는"
- 거부감 포인트: 매니큐어 붓처럼 생긴 도포구

### 세컨더리 — 여성 (구매결정자·여론형성자)
- "내 남자친구가 이런 거 쓰면 좋겠다" 심리
- 선물 구매, SNS 공유, 구전 확산 역할

### EP 시리즈 세계관 (넷플릭스식 잠금·리빌)

| 에피소드 | 타깃 부위 | 상태 |
|---------|---------|------|
| EP1 | 손톱 | 현재 출시 |
| EP2 | 큐티클 | 리빌 예정 |
| EP3 | 입술 | 리빌 예정 |
| EP4 | 발 | 리빌 예정 |

## 4겹 해자 (경쟁 방어막)

| 레이어 | 내용 | 방어 강도 |
|--------|------|---------|
| Layer 1 — 출처 | 실제 운영 중인 살롱 리버니가 만든 제품. "진짜 샵·진짜 손·진짜 결과" | 중 (협업으로 모방 가능 — 여기서 멈추면 안 됨) |
| Layer 2 — 독자 처방 | 실사용 고객 수백 명 데이터로 다듬은 OEM 독점 처방 | 높음 (데이터·독점 처방은 못 베낌) |
| Layer 3 — 관계 | 매장 → 집 루틴 → 구독으로 이어지는 감정적 충성 | 높음 (감정 충성은 가격으로 못 빼앗김) |
| Layer 4 — 콘텐츠·데이터 복리 | 비포/애프터·후기·재구매 데이터 라이브러리 축적 → 신제품 CAC 절감 | 높음 (시간 자체가 진입장벽) |

## APR vs 블랭크 교훈 적용

| 구분 | 내용 |
|------|------|
| 블랭크 (회피) | 해자 없이 콘텐츠만, 본업과 무관한 곁가지 확장, 단발 히트 의존, SKU 남발 |
| APR (추구) | D2C 데이터 확보, 재구매 잠금 구조, 한 축(네일)에 집중, 콘텐츠 역량 내재화 |
| APR 너머 | APR 약점(ODM 한계·광고 의존·체험 없음) → 살롱 체험·독자처방·커뮤니티로 보완 |

> APR이 약한 자리가 정확히 우리가 강한 자리다. APR = "제품 파는 회사", 리버니 = "경험·관계·제품을 함께 파는 회사".

## 수익 스트림 (4개)

| 스트림 | 내용 | 단계 |
|--------|------|------|
| i. D2C 제품 | 자사몰·스마트스토어. 고마진·재구매 | 지금부터 |
| ii. 매장 시술 | 현금흐름 + 콘텐츠 촬영장 + 제품 검증소 | 운영 중 |
| iii. B2B 도매 | 다른 네일샵에 "프로가 쓰는 제품" 공급 | 검증 후 |
| iv. 구독·교육 | 오일 정기배송 + 셀프 케어 클래스 | 성장기 |

## 확장 브랜딩 — "느좋 남자의 필수템"

> "차별화된 관리 잘된 남자가 되려면 찾는 필수 브랜드" 포지셔닝.  
> 단, **1년차엔 손톱 하나에 집중.** 이 큰 그림은 EP가 쌓인 뒤 드러낸다.

### 확장 경로 (에피소드 = 제품 라인)

| EP | 카테고리 | 제품 방향 |
|----|---------|---------|
| EP1 손톱 | 케어 세럼 | 물어뜯기·갈라짐·거스러미. **진입점.** |
| EP2 큐티클·손 | 큐티클 오일·핸드 디테일 | 브러시형 정밀 제품 |
| EP3 입술 | 립 세럼 | 입술 각질·뜯는 습관 (손톱과 행동 연결) |
| EP4 발·기타 | 발톱·뒤꿈치 풀라인 | 놓치는 부위. 디테일 풀 라인. |

### 최종 포지셔닝

**"바디테일 = 관리 잘된 남자의 디테일 케어 필수 브랜드."**  
향수·헤어처럼 "느좋(느낌 좋은) 남자라면 당연히 챙기는" 카테고리로 자리매김.  
남성 그루밍 시장에서 손톱·디테일 영역은 아직 비어있다 — **지금 깃발을 꽂을 수 있음.**

> 순서: 손톱으로 각인 → 신뢰·재구매 증명 → 그 다음 확장 선언.  
> "손톱? 입술? 발? 뭐 파는 데지?"로 흐려지지 않게 — **비전은 품되, 입은 좁게.**
