# 브랜드 핵심 (바디테일)

## 브랜드명 결정
- 브랜드명: **바디테일 (bodetail)** = body + detail
- 구조: 인스타·브랜드 = 바디테일 / 사업자 = 리버니 네일케어 / "리버니가 만든 바디테일"
- 핸들: @bodetail (예정)

## 페르소나
- 메인: 20~30대 남성 사용자 (블루오션)
- 여성: 구매결정자·여론형성자 ("내 남친이 이런 거 쓰면 좋겠다")
- 에피소드 세계관: EP1 손톱 → EP2 큐티클 → EP3 입술 → EP4 발 (넷플릭스식 잠금/리빌)

## 비주얼 토큰
- 컬러: 옥스블러드 #6B1620 / 딥 #46101A / 포슬린 #F2ECE6 / 골드 #B0844A
- 폰트: 제목 = Fraunces(세리프), 본문 = Pretendard
- 로고 6안: 01 모노그램 bd ★ / 02 스택세리프 / 03 닷 / 04 둥근 b 아이콘 ★ / 05 테일라인 / 06 라이트 by-libunny
- 프로필 추천: 01·04

## 인플루언서 협찬 전략
- 2축: ① 워너비 남성(스완 1위-현실남자관리, 깡 2위-패션 126만, 관리는하고살자 3위 김정원) ② 여론 여성(연애/데일리/뷰티)
- 1년차: 메가 비추, 결 맞는 마이크로(1만~10만)·미들 분산
- 우연(@우연w): 유튜브 19.3만, 무신사 큐레이터, 175/70 현실남 데일리캐주얼 — 매우 좋은 타깃
- 멋랩: 18.8만 30대 쉬운패션
- 핵심 인사이트: 협찬 = "website 선물" 아닌 **"릴스 viral 도와주기"** 프레이밍
