## 1. 혀 클리너 (Tongue Scraper)

### 시장
구강용품 VOC 분석에서 혀클리너가 구취 제거 목적으로 높게 언급됨. 글로벌 구강케어 시장 2023년 484억 달러, CAGR 4.18%로 2031년 669억 달러 전망. 혀클리너 단독 시장은 작지만 구강케어 전체 성장세를 탐.

### 경쟁 현황
- 다이소·쿠팡 기준 1,000~5,000원대 저가 범람
- 국내 브랜드다운 브랜드 없음 (거의 무브랜드 or 수입)
- 고급 혀클리너(스테인리스, 구리 소재) = 해외 직구만 가능

### 차별화 가능성
- **에스프레소+오프화이트 컬러 스테인리스 혀클리너** — 지금 시중에 없음
- "구강도 디테일" — EP3(입술)과 자연스럽게 연결
- 단가 낮아서 번들 구성에 유리 (손톱 오일 + 혀클리너 "입 주변 디테일 세트")
- BFRB 연결: 입술 뜯는 사람이 구강에도 예민 → 같은 페르소나

### 제조 난이도
스테인리스/구리 금형 → ODM 쉬움. 알리 OEM도 가능한 수준.

### 평가
| 항목 | 점수 |
|---|---|
| 시장 크기 | ★★★☆☆ |
| 경쟁 강도 (낮을수록 좋음) | ★★★★☆ (경쟁 약함) |
| 차별화 가능성 | ★★★★☆ |
| 세계관 연결성 | ★★★★☆ |
| 제조 난이도 (쉬울수록 좋음) | ★★★★★ |
| **종합** | **★★★★☆** |

**결론: 추천. EP3 입술과 번들로 묶으면 시너지 큼. 단가 낮아서 단독 제품보다 세트 구성에 유리.**

## 2. 헤어 픽서 (Hair Wax/Fixer)

### 시장
국내 남성 헤어왁스 시장은 Gatsby가 오랫동안 지배해왔고, 대안 제품 수요가 꾸준히 있음. 2026년 남자 헤어스타일 트렌드 핵심은 자연스러움+손질 편의성.

### 경쟁 현황
- **극강의 레드오션.** Gatsby, 루시드폼, 미장센, BodyShop, American Crew 등 수십 개
- 올리브영 헤어왁스 SKU만 수십 가지
- 이미 강력한 브랜드들이 점령한 시장

### 차별화 가능성
- 성분 차별화(무실리콘, 천연 왁스) → 이미 다 있음
- 디자인 차별화 → 패키지 예쁜 왁스도 이미 많음
- "남성 그루밍 디테일" 각도는 있지만 진입 장벽이 너무 높음

| 경쟁 강도 | ★☆☆☆☆ (극심한 경쟁) |
| 차별화 가능성 | ★★☆☆☆ |
| 세계관 연결성 | ★★☆☆☆ |
| 제조 난이도 | ★★★☆☆ |
| **종합** | **★★☆☆☆** |

**결론: 비추천. 레드오션 중 레드오션. 바디테일이 이겨낼 수 있는 시장이 아님.**

## 3. 데오드란트 (Deodorant)

### 시장
글로벌 남성 미용 시장 2025년 4,863억 달러, CAGR 6.6%로 2034년 8,645억 달러 전망. 데오드란트는 이 시장의 핵심 카테고리.

### 경쟁 현황
- 니베아, 도브, AXE, 레세나, 비오템 등 글로벌 공룡
- 국내 데오드란트 시장도 이미 브랜드 포화
- 단 "천연·무알코올·피부 순한" 니치 데오드란트는 성장 중

### 차별화 가능성
- **겨드랑이 BFRB 연결**: 긁는 습관, 옷에 냄새 배는 것에 예민한 사람 → 연결 가능하나 억지스러움
- "프리미엄 남성 데오드란트" 각도: 국내엔 아직 프리미엄 포지션 없음
- 단 글로벌 브랜드 대비 신뢰도 쌓기가 너무 오래 걸림

### 평가
| 항목 | 점수 |
|---|---|
| 시장 크기 | ★★★★★ |
| 경쟁 강도 | ★★☆☆☆ (강함) |
| 차별화 가능성 | ★★★☆☆ |
| 세계관 연결성 | ★★☆☆☆ |
| 제조 난이도 | ★★★☆☆ |
| **종합** | **★★★☆☆** |

**결론: 보류. 시장은 크지만 우리 세계관(BFRB·디테일)과 연결이 약함. EP 시리즈에 넣기 어색함.**

## 4. 괄사 (Gua Sha)

### 시장
괄사는 2020~2022년 여성 뷰티 붐 이후 남성 시장 진입 중. 국내 남성 괄사 제품은 거의 없음.

### 경쟁 현황
- 국내: 여성용 괄사 범람, 남성 타깃은 공백에 가까움
- 해외: Hailey Bieber 효과로 인지도 급상승했으나 한국 남성 시장은 아직 초기

### 차별화 가능성
- **"남성 얼굴 윤곽 괄사"** — 사각턱, 부기 제거 각도로 어필 가능
- 에스프레소+골드 컬러 스테인리스 or 흑요석 괄사 → 디자인 차별화 확실
- BFRB 연결: 피부 긁는 습관(피부 뜯기, 여드름 짜기)과 연결 가능
- 단 괄사는 "사용법 교육"이 필요 → 콘텐츠 제작 부담

### 평가
| 항목 | 점수 |
|---|---|
| 시장 크기 | ★★★☆☆ |
| 경쟁 강도 | ★★★★☆ (남성 시장 거의 없음) |
| 차별화 가능성 | ★★★★☆ |
| 세계관 연결성 | ★★★☆☆ |
| 제조 난이도 | ★★★★☆ |
| **종합** | **★★★★☆** |

**결론: 흥미로운 후보. "남성 얼굴 디테일" EP 신설 가능. 단 사용법 콘텐츠가 많이 필요해서 콘텐츠 파워 생긴 후 진입 추천.**

## 5. 피부 때 (바디 스크럽/각질 제거)

### 시장
남성 스킨케어 제품 시장 2024년 196억 달러, CAGR 4.9%로 2034년까지 성장 전망. 바디 각질 제거는 남성도 꾸준한 수요.

### 경쟁 현황
- 올리브영: 바디 스크럽 제품 이미 다수
- 니베아, 뉴트로지나, 불리1803 등 이미 다양함
- "남성 전용 바디 스크럽" 브랜드는 드물지만 일반 바디 스크럽과 실질 차이 없음

### 차별화 가능성
- **피부 뜯기 BFRB 각도**: 등드름 짜기, 각질 뜯기 습관 → "긁지 않고 스크럽으로" 전환
- 단 이 BFRB 연결은 손톱·입술보다 설득력이 약함
- 바디 스크럽 자체로는 차별화 포인트 찾기 어려움

## 6. 니플 패치 (Nipple Cover/Patch)

### 시장
운동·헬스 후 니플 마찰 방지 수요. 마라톤 러너, 헬스인 중 실사용자 많음. 국내 남성 니플 패치 = 아직 브랜드화된 제품 거의 없음.

### 경쟁 현황
- 국내: 무브랜드 의료용 테이프 or 여성용 제품 전용
- 해외: NIPPIES, Manscaped 등 남성 그루밍 브랜드에서 취급
- **국내 남성 타깃 브랜드 제품 = 공백**

### 차별화 가능성
- **"운동하는 남자 디테일"** — 헬스·러닝 커뮤니티에서 실사용 수요 확실
- 피부 자극 없는 저자극 소재(실리콘/하이드로콜로이드) + 바디테일 패키지
- BFRB 연결: 긁거나 뜯는 행동이 니플 주변에도 나타날 수 있음 (억지스럽긴 함)
- 사실 BFRB보다 **"운동 디테일"** 각도가 더 설득력 있음

### 평가
| 항목 | 점수 |
|---|---|
| 시장 크기 | ★★★☆☆ |
| 경쟁 강도 | ★★★★★ (국내 남성 제품 없음) |
| 차별화 가능성 | ★★★★☆ |
| 세계관 연결성 | ★★★☆☆ |
| 제조 난이도 | ★★★★☆ |
| **종합** | **★★★★☆** |

**결론: 흥미로운 틈새. 국내 공백이 확실하고 헬스·러닝 커뮤니티 공략 가능. 바디테일 세계관 "신체 디테일 전반"으로 확장 시 자연스럽게 포함 가능.**

## 7. 잔털 제거 (Body Hair Removal)

### 시장
글로벌 제모 제품 시장 2025년 141억 달러, CAGR 4.7% 성장 전망. 남성 제모 수요 꾸준히 증가 중.

### 경쟁 현황
- 왁싱, 면도기, 제모크림(비트, 네어), IPL 기기 등 다양한 방식
- 남성 전용 제모 브랜드: Manscaped(미국), 국내는 아직 약함
- 국내 올리브영 기준 여성 제모 제품은 다양, 남성은 부족

### 차별화 가능성
- **"남성 잔털 디테일"** — 손등, 손가락, 귀, 이마 라인 등 부위 특화
- 특히 **손가락 잔털 제거**는 EP1(손톱)과 자연스럽게 연결 → "손끝 디테일 완성"
- 크림형 제모제 + 바디테일 패키지 → "손끝 케어 세트 (오일+제모크림)" 번들 가능
- BFRB: 털 뽑기(Trichotillomania)도 BFRB의 일종 → 세계관 연결 가능

### 평가
| 항목 | 점수 |
|---|---|
| 시장 크기 | ★★★★★ |
| 경쟁 강도 | ★★★☆☆ (남성 특화 약함) |
| 차별화 가능성 | ★★★★☆ |
| 세계관 연결성 | ★★★★☆ |
| 제조 난이도 | ★★★☆☆ |
| **종합** | **★★★★☆** |

**결론: 강력 추천 후보. 특히 "손가락 잔털 제거"는 EP1 손톱케어와 직결. "손끝 완성 세트"로 번들화 가능. BFRB 연결도 자연스러움.**

## 바디테일 EP 시리즈 업데이트 제안

기존 EP 구성에 추가:
```
EP1 손톱 케어 오일 (진행 중)
EP2 큐티클 케어
EP3 입술 케어
  └── 번들: 혀 클리너 포함 "입 주변 디테일 세트"
EP4 발 케어
  └── 번들: 발톱 오일 + 발뒤꿈치 크림
EP5 (신설) 손끝 완성
  └── 손가락 잔털 제거 크림 + EP1 오일 세트
EP6 (신설) 얼굴 디테일
  └── 괄사 + 남성 피부 롤온
EP7 (신설) 바디 디테일
  └── 니플 패치 + 바디 케어
```
