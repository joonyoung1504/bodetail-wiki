# raw 폴더 안내

이 폴더에는 바디테일 사업의 핵심 자료가 들어 있다.
정리된 마크다운(01~05)과 원본 문서(원본_*.html/.md/.txt)가 섞여 있다.

## 클로드 코드에게 시킬 것
아래처럼 지시하면 이 자료들을 위키로 정리한다:

"raw/ 폴더의 01~05 마크다운과 원본_* 문서들을 읽고, 위키 규칙대로 정리해줘.
- 01_제품_핵심정보 → product/ 폴더로
- 02_브랜드_핵심 → brand/ 폴더로
- 03_시장_경쟁사 → market/ 폴더로
- 04_OEM_업체현황 → ops/ 폴더로
- 05_의사결정_기록 → decisions/ 폴더로
- 원본 HTML들은 핵심 내용을 요약해 해당 폴더 노트에 반영(원본은 raw/에 보존)
각 노트에 frontmatter(summary·tags·created·updated)를 달고, 관련 노트끼리 [[링크]]로 연결해줘."

## 분류 가이드
- 제품/처방/용기 → product/
- 브랜드/페르소나/로고/인플루언서 → brand/
- 시장/경쟁사/재무 → market/
- OEM/견적/일정 → ops/
- 왜 그렇게 정했나 → decisions/
