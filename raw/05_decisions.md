# 주요 의사결정 기록

## 제형: 무수 오일로 결정
- 이유: 희망 성분이 수상+유상 혼재 → 물 들어가면 방부 필수. 무수면 방부 불필요·저자극.
- 출처: 라온하제 제안 수용

## 용기: 롤온 1순위
- 이유: 손톱·큐티클 조준 도포 + 마사지감. 스프레이는 조준·점도·마사지 모두 불리.
- 펜팁 2순위: 남성 타깃이 매니큐어 붓에 거부감 → 도포구 형태만 변경

## "회복" 표현도 빼기
- 이유: 화장품법상 "회복"이 손상 되돌림=의약품적 효능으로 해석 위험 (라온하제 지적)
- 대체: 보습·관리·정돈·영양·케어

## 1순위 OEM = 라온하제 20ml 1,500개 (잠정)
- 이유: 롤온 충진 일괄 확답 + MOQ 최소(1,500개) + 재고 리스크 절반
- 단 단가·소비자가·수요검증 미확정 → 양산 결정 보류, 샘플 먼저

## 도구: 지금은 Claude Code 단일, 나중에 Ollama 하이브리드
- 이유: 검증 전엔 단순함>비용절감. 대량 자동화 시 Ollama로 반복작업 떼어 토큰 절감
- 안티그래비티는 Ollama 하이브리드용 (지금 부적합)

## 세컨드 브레인: 콘텐츠 자동화 볼트 + LLM 위키 볼트 분리
- 이유: 이질적 자료 한 볼트에 섞으면 컨텍스트 오염
- 위키 = 사업 두뇌(지식), 콘텐츠 = 공장. 보완 관계

## 핵심 전략 방향
- 토리든식 오가닉+재구매 (셀라딕스식 광고물량 X)
- 수요 검증(인스타 반응) 먼저, 양산은 그 후
- 반복 지적: "만들기 과몰입, 팔기 검증 0" → 수요 검증으로 에너지 전환 필요

## 5년 재무 목표
- 5년 2억 저축 = 직장인 상위 5~10% 저축속도, 매우 보수적
- 전제: 1년차 재구매 증명 → 2년차 점프 → 5년 생존
