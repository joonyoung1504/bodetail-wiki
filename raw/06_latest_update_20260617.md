# 2026-06-17 최신 결정사항

## 라온하제 회신 분석 + 잠정 결정

### 잠정 결정: 라온하제 20ml 1,500개
- 이유: 롤온 충진 자사 일괄(확답) + MOQ 최소치 + 재고 리스크 절반
- 라온하제 MOQ = 총중량 약 30kg 기준
  - 10ml → 3,000개 / 5ml → 6,000개 / **20ml → 1,500개**
- 3,000개는 원래 5,000개부터인데 특별히 최소치로 깎아준 것
- 단가는 처방·용기 확정 후 산출 (아직 미정)

### 라온하제 회신 핵심 내용
- 무수 드라이 오일 처방 권장 (수상+유상 혼재 피해 방부 불필요)
- "닿아도 아프지 않을 만큼 순한" 표현 → 양산 시 재검토 조건부 가능
- **"회복"도 위험** (의약품적 효능으로 해석 가능) → "보습·관리·정돈"으로
- 피·열린 상처엔 사용 불가 (의약품 영역)
- 롤온/펜팁은 처방이 달라서 동시 개발 시 비용·MOQ 두 배
- 데나토늄(쓴맛 자각) 버전 가능 확인
- 색상: 아르간 등 원료 고유색 있어 완전 투명 불가 → "맑은 오일색"
- 롤론 위생: 사용 후 휴지로 닦기(물세척 X), 상처엔 볼 직접 안 대기
- 샘플: 22만원, 최초+수정1회(총 2번), 2주
- 라온하제 샘플 진행 메일 발송 완료

## 세컨드브레인 5대 보완 계획

### 결함과 해결책
1. **수작업 입력 → 메타 API 자동 수집**
   - 팔로워 1,000명+ 비즈니스/크리에이터 계정 필요
   - API 제공: views, reach, saved, shares, reels_skip_rate 등 핵심 지표
   - API 미제공(스크린샷 보조): 3초 잔존율, 구간 이탈, 도달출처 세부

2. **통계 없음 → 표본·신뢰도 장치**
   - sample_size 5미만=참고 / 10+= 신뢰
   - Insight status: hypothesis → testing → validated
   - is_outlier 필드로 이상치 제거

3. **변수 과다 → 핵심 7개 우선**
   - hook_type / first3sec / opening_line / caption_copy / cta_type / publish_time / topic
   - 나머지는 사전 보관, 핵심 7개 안정 후 실험

4. **루프 끊김 → 발행 큐**
   - 상태: 대기 → 발행됨 → 결과수집중 → 분석완료
   - "같은 변수 실험은 직전 결과 들어온 뒤에만"

5. **노이즈 → 이상치 제거**
   - anomaly_note: 외부요인(인플루언서 공유 등) 기록
   - 평균 3배 이상 성과는 outlier로 표시, 성공방정식 계산에서 제외
