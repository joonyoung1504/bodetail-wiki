# 바디테일 × 그루밍 브랜드 콜라보 할인전 전략

## 핵심 아이디어

우리 사이트(스마트스토어 or 자사몰)에서 **"이달의 디테일 픽"** 형식으로
매월 1~2개 남성 청결·그루밍 브랜드 제품을 기간 한정 할인가로 판매.

```
바디테일 제품 + 이달의 픽 (콜라보 브랜드) = 묶음 구성
→ 바디테일 구매 고객에게 자연스럽게 노출
→ 콜라보 브랜드는 우리 고객에게 무료 마케팅
→ 우리는 콘텐츠 소재 + 트래픽 증가 + 수익 일부
```

## 운영 방식 — "이달의 디테일 픽"

### 기본 구조
```
매월 1일: 이달의 픽 브랜드 발표 (인스타 예고)
1일~말일: 우리 사이트에서 해당 제품 기간 한정 할인
다음달 1일: 새 브랜드로 교체
```

### 할인 구조
- 정가 대비 15~25% 할인
- 바디테일 제품과 묶음 구성 시 추가 5% 할인
- "바디테일 구매 고객 전용 할인코드" → 우리 고객 락인 효과

### 수익 구조
**방법 A — 위탁 수수료형**
- 콜라보 브랜드가 우리 스토어에 제품 위탁
- 판매가의 20~30%를 우리가 수수료로 가져감
- 재고 없음, 리스크 없음

**방법 B — 매입 후 재판매형**
- 우리가 공급가에 매입 → 15~25% 할인가에 판매
- 마진 차이로 수익 + 할인 효과도 줌
- 리스크는 있지만 마진 더 큼

**방법 C — 번들 세트 구성 (추천)**
- "바디테일 손톱 케어 오일 + 이달의 픽" 세트 구성
- 바디테일 단독보다 객단가 높아짐
- 예: 바디테일 25,000원 + 혀클리너 8,000원 = 세트 28,000원 (5,000원 할인)

## 콘텐츠 마케팅 연계

### 릴스 활용
매달 콜라보 발표를 릴스로:
```
"이번달 남자 청결 루틴 추천" (정보형)
→ 바디테일 + 이달의 픽 브랜드 소개
→ 둘 다 쓰면 "손끝부터 입까지" 완성 스토리
```

### 콜라보 브랜드 인스타 교차 홍보
- 우리가 그들 태그 → 그들이 우리 스토리 공유
- 팔로워 교환 효과 (특히 초기 팔로워 0에서 벗어나는 데 효과적)
- 소규모 D2C 브랜드일수록 협업 의향 높음

## 초기 접근 전략 — 현실적 순서

### 지금 당장은 불가. 선행 조건:
1. 인스타 팔로워 최소 500명
2. 릴스 10개 이상
3. 스마트스토어 개설 + 바디테일 정식 출시

### 첫 콜라보 타깃 — 이글립스

이유:
- 국내 D2C 브랜드라 DM으로 접근 쉬움
- 구강 케어 = EP3(입술)과 자연스러운 연결
- 우리와 타깃 비슷 (청결에 관심 있는 남성)
- 규모가 적당해서 협업 제안 받아들일 가능성 높음

### DM 접근 예시 (이글립스)
```
안녕하세요, 바디테일입니다.
저희는 남성 손톱 케어 오일 브랜드인데요,
구강 케어까지 신경 쓰는 디테일한 남성 타깃이 
이글립스와 완전히 겹친다고 생각해서 연락드렸어요.

저희 스토어에서 이달의 픽으로 이글립스 제품을
한 달간 소개하고 싶은데, 관심 있으시면 연락 주세요 🙏
```

## 장기 비전 — "남성 디테일 큐레이션 플랫폼"

바디테일이 단순 제품 브랜드를 넘어서
**"디테일한 남자를 위한 청결 큐레이터"** 포지션으로 확장.

```
바디테일 사이트 = 남성 청결·그루밍 제품 큐레이션
매달 새 브랜드 → 구독 고객은 항상 새로운 픽 발견
→ 재방문율 상승, 체류 시간 상승, 신뢰도 축적
```

이게 쌓이면 나중에 "바디테일이 추천하면 믿는다"는 신뢰 자산이 됨.
이 신뢰 자산이 EP 시리즈 신제품 출시 때마다 즉각적인 구매로 전환.
