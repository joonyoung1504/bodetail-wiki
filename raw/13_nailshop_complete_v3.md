# 바디테일 × 네일샵 제휴 완전판

## 1. Nailtiques vs 바디테일 성분 비교

### Nailtiques 기본 정보
- 형태: 롤러볼 큐티클 오일
- 용량: 10ml (0.33oz)
- 가격: 미국 $12~18 / 국내 직구 23,000원
- 타깃: 여성 범용 큐티클 보습
- 영업이익률·매출: 비상장 사기업 비공개

### 전성분 비교

**Nailtiques**: Water, 해바라기씨오일, 잇꽃씨오일, 아보카도오일, 헴프씨오일, 티트리오일, 향료, 비타민E, 비타민A(레티닐팔미테이트)

**바디테일**: 호호바오일, 아르간오일, 스쿠알란, 세라마이드, 병풀추출물(마데카소사이드), 알란토인, 가수분해케라틴, 비오틴, 판테놀, 비타민E

### 분야별 성분 우위

| 분야 | Nailtiques | 바디테일 | 승자 |
|---|---|---|---|
| 변형 손톱 복구 | 비타민A (세포재생) | 가수분해케라틴·비오틴·판테놀 | **바디테일** |
| 보습 지속 | 수성베이스(증발빠름) | 무수오일·세라마이드 (피부장벽) | **바디테일** |
| 상처·거스러미 진정 | 티트리(항균but자극) | 병풀·알란토인(저자극 진정) | **바디테일** |
| 세균 침투 억제 | 티트리 직접항균 | 세라마이드 장벽강화(간접) | Nailtiques |
| 남성 타깃 특화 | ❌ 범용 여성 | ✅ BFRB 남성 | **바디테일** |
| 국내 접근성 | 직구만 가능 | 국내 브랜드 | **바디테일** |
| ml당 가격 | 2,300원/ml | 약 1,100원/ml | **바디테일** |

### 핵심 차이 한 줄
Nailtiques = 여성 큐티클 보습 범용. 바디테일 = 남성 BFRB 케어 특화. 카테고리 자체가 다름.

### 습관 개선에 대한 솔직한 입장
어떤 화장품 성분도 습관을 고쳐주지 않음. 습관 개선은 "롤온으로 매일 바르는 루틴 형성" 자체가 핵심. 성분이 아니라 브랜드 컨셉과 마케팅으로 만드는 가치.

## 4. 결제 구조 — 할인코드로 돈이 우리에게 직접 오는 구조

### 핵심 원칙
원장은 "판매 직원"이 아니라 "소개자". 고객이 직접 우리한테 결제 → 위조 불가. 원장은 소개비만 받는 구조.

### 전체 흐름
```
원장 → 시술 끝난 고객에게:
       "이 QR로 들어가서 [샵 코드] 입력하면 3,000원 할인돼요"

고객 → QR 스캔 → 우리 스마트스토어
     → 코드 입력 → 22,000원 결제 (돈은 우리한테 직접)

우리 → 코드별 판매량 자동 집계
매월 말 → 우리가 원장에게 판매수 × 5,000원 입금
```

### 수익 구조 (A안 — 권장)

| 항목 | 금액 |
|---|---|
| 정가 (소비자가) | 25,000원 |
| 할인코드 적용가 (고객 결제) | **22,000원** |
| 할인율 | 12% |
| 원장 소개비 (우리가 월말 정산) | **5,000원** |
| 우리 원가 | 6,000원 |
| **우리 순이익** | **11,000원** |
| 우리 영업이익률 | **50%** |

계산: 22,000 - 5,000 - 6,000 = **11,000원**

### 시나리오 비교

| 구조 | 고객결제 | 할인율 | 원장소개비 | 우리순이익 |
|---|---|---|---|---|
| A안 (권장) | 22,000원 | 12% | 5,000원 | **11,000원** |
| B안 | 21,000원 | 16% | 5,000원 | **10,000원** |
| C안 | 22,000원 | 12% | 7,000원 | **9,000원** |

A안 권장 이유: 원장 소개비 5,000원은 충분한 동기, 우리 순이익 11,000원으로 원가 대비 183% 마진.

### 이 구조의 강점

- **위조 불가**: 돈이 우리 스토어로 직접 → 코드별 판매량 시스템이 자동 기록
- **원장 동기 생성**: 내 코드로 팔수록 수입 증가 → 자발적 홍보
- **고객 구매 동기**: "할인받는다"는 심리 → 전환율 상승
- **일반 소비자는 정가**: 코드 없이 구매 시 25,000원 그대로 → 온라인 정가 유지
- **매장 방문 불필요**: 코드별 집계 자동 → 원격 관리 가능

### 스마트스토어 실무 세팅
1. 제품 정가 25,000원 등록
2. 매장별 쿠폰코드 생성 (RIBBONY, BITDAM, CLOUD 등 샵명 기반)
3. 코드당 할인금액: 3,000원 고정
4. 코드 사용횟수: 무제한 (한 매장 고객 계속 사용 가능)
5. 월말 코드별 사용횟수 확인 → 원장에게 5,000원×횟수 입금

### 원장에게 주는 홍보물
QR코드 + 코드 안내 카드 (A6 사이즈):
```
┌─────────────────────────────┐
│  시술 후 홈케어                │
│  바디테일 손톱케어 오일          │
│                              │
│  [QR코드]                    │
│                              │
│  할인코드: [RIBBONY]          │
│  정가 25,000원 → 22,000원    │
│  (3,000원 할인)               │
└─────────────────────────────┘
```
원장은 이 카드를 시술 끝난 고객에게 건네주기만 하면 됨.

### 구현 체크리스트
- [ ] 네이버 스마트스토어 개설
- [ ] 제품 등록 (25,000원, 사진·설명 완비)
- [ ] 매장별 쿠폰코드 생성
- [ ] A6 홍보 카드 인쇄 (샵당 10~20장)
- [ ] 정산 주기 합의: 매월 말일 기준 → 5영업일 이내 입금

1. 물어뜯는 손톱 포스팅 3개 이상

## 6. 제휴 접근 대본

### DM 첫 메시지
```
안녕하세요 원장님 😊

물어뜯는 손톱 교정 포스팅 보고 연락드렸어요.
저희도 네일샵(리버니 네일, 서울 문정동) 운영하면서
물어뜯는 손톱 고객분들을 위한 남성용 롤온 케어 오일을 만들었어요.

시술 후 홈케어로 추천해주시면
재고 부담 없이 판당 10,000원 수익이 생기는 구조예요.

샘플 한 번 받아보시겠어요? 🙏
```

### 방문 미팅 대본 (핵심만)

[공감] "저희도 네일샵 하면서 느꼈어요. 시술은 잘 해드렸는데, 집에 가면 또 뜯으시더라고요."

[제품] "롤온이라 (시연) 이렇게 굴리기만 해요. 남성분들도 거부감 없어요. 무수오일이라 끈적임 없이 흡수되고요."

[핵심 제안] "재고 부담 없이 저희가 진열해드릴게요. 샵 카운터에 QR코드 카드 두면 고객이 직접 결제해요. 원장님은 판매 확인 없이 월말에 판매수 × 10,000원이 입금돼요."

[숫자] "한 달에 물어뜯는 손톱 고객 10명 중 3명만 사가셔도 30,000원이에요. 따로 하실 게 없어요."

[클로징] "일단 진열 카드 3장만 놓아보시고, 한 달 후 결과 보시고 계속 여부 결정해주세요."

### 예상 반론 대응

"우리 고객은 여성이 많아서요"
→ "여성 고객분들이 남자친구·남편한테 사가시는 경우 많아요. 사실 그게 더 큰 시장이에요."

"잘 팔릴지 모르겠어요"
→ "QR 구조라 팔리면 자동 정산이고, 안 팔리면 원장님 손해가 없어요."

"가격이 비싸지 않나요"
→ "시술받으러 오신 분들은 10만원 이상 쓰시잖아요. 2.5만원은 자연스러운 홈케어 추가예요."

## 7. 실행 타임라인

| 시점 | 할 것 |
|---|---|
| 지금 | 인스타 팔로워 500명, 릴스 5개 목표 |
| 샘플 완성 후 | 스마트스토어 개설 + QR 카드 제작 |
| 파일럿 5개 샵 | QR 위탁 모델 테스트 |
