# 릴스 제작 표준 프로세스 (재사용 템플릿)

## 핵심 도구
- **편집 앱: 캡컷(CapCut)** — 무료, 모바일/PC 둘 다. 릴스 90%가 이걸로 만듦
- **샤갈 목소리 = 캡컷 TTS 'Adam(애덤)' 모델** — 외국인이 국어책 읽는 듯한 유행 톤
- 실사 이미지/영상은 직접 촬영해서 캡컷에 올림

## 7단계 제작 흐름 (모든 릴스 공통)
1. 대본 확정 (훅·전개·반전·CTA / 자막 문구 단위로 쪼갬)
2. 필요한 화면(컷) 목록 정리 → 실사 촬영 or AI 생성
3. 캡컷에 소스 올리기 (사진/영상)
4. TTS 음성 입히기 (Adam, 속도 1.2)
5. 자막 깔기 (TTS와 싱크)
6. BGM + 효과음 + 전환
7. 9:16 비율 확인 → 내보내기 → 인스타 업로드

## 캡컷 TTS 샤갈(Adam) 적용법 — 외워두기
1. 캡컷 앱 실행 → 새 프로젝트
2. 텍스트 → 텍스트 추가 → 자막 문구 입력
3. 입력한 텍스트 선택 → "텍스트 음성 변환(Text to speech)"
4. 남성 카테고리 → **Adam(애덤)** 선택
5. 속도 **1.2배**로 변경 (더 트렌디하고 찰지게)
6. 적용 → 각 자막마다 반복
- 팁: 문장을 짧게 끊어야 샤갈 특유의 "툭툭" 끊기는 맛이 산다

# EP1 길거리 투표 — 완성 대본

## 콘셉트
유쾌·반전. 샤갈 톤으로 진지한 척하다가 손톱으로 반전. "남자도 손톱 본다"를 웃기게 각인.

## 영상 길이: 약 14초 / 9:16 세로

## 컷별 대본 (자막 = TTS Adam 음성, 속도 1.2)

### [0~3초] 훅
- **TTS/자막**: "이성을 볼 때… 의외로 가장 신경 쓰이는… 신체 부위 1위는?"
- **화면**: 긴장감 주는 검은 배경 + 흰 자막, 또는 거리 풍경. 두구두구 효과음
- **BGM**: 긴장감/두구두구 (캡컷 '긴장' 검색)

### [3~5초] 보기 제시
- **TTS/자막**: "후보. 1번 손톱. 2번 겨드랑이 땀자국. 3번 떡진 머리."
- **화면**: 세 후보를 자막 카드로 빠르게 (각 1초씩). 가능하면 각 부위 사진

### [5~10초] 투표/반응
- **TTS/자막**: "사람들에게 물어봤다." → "어..? 손톱?" "생각보다 손톱 많이 봐요" "지저분하면 좀…"
- **화면**: 지인 인터뷰 컷 (또는 손톱 클로즈업 여러 개 + 반응 자막). 의외라는 리액션

### [10~13초] 반전
- **TTS/자막**: "그렇다. 의외로 손톱을 많이 본다. 근데… 가장 방치하는 부위이기도 하다."
- **화면**: 깔끔한 손 vs 거친 손 비교 클로즈업

### [13~14초] CTA
- **TTS/자막**: "당신은… 손톱… 자신 있나?"
- **자막(고정)**: "댓글로 알려줘 👇 @bodetail"
- **화면**: 브랜드 로고 살짝 + 프로필 유도

## 캡션 (게시물 본문)
```
남자도 손톱 봅니다 (팩트)
솔직히 본인 손톱 자신 있는 사람? 손?
.
.
곧 남자 손끝을 위한 게 나옵니다 👀
출시 알림은 프로필에서
.
#손톱 #남자그루밍 #네일케어 #자기관리 #손톱뜯기 #그루밍 #남자손톱 #바디테일
```

## 첫 댓글 (본인이 바로 달기)
"여러분은 몇 번 골랐나요? 저는… 솔직히 손톱 자신 없어서 이 브랜드 시작했어요 ㅋㅋ"

## 필요한 실사 촬영 컷 (준영이 찍어서 제공)
1. **손톱 클로즈업 — 거친/물어뜯은 상태** (반전·비교용) ★필수
2. **손톱 클로즈업 — 깔끔한 상태** (비교용) ★필수
3. (선택) 겨드랑이 땀자국 느낌, 떡진 머리 — 없으면 자막 카드로 대체 가능
4. (선택) 지인 1~2명 "손톱?" 반응 인터뷰 — 없으면 TTS 내레이션 + 손톱샷으로 대체
- ※ 1·2번만 있어도 영상 완성 가능. 3·4는 있으면 더 좋음

## 규제 체크 (항상)
- "치료·완치·회복" 금지 → 이 영상엔 효능 주장 없음(인식 환기형이라 안전)
- 제품 언급은 "곧 나옵니다" 수준 (효능 단정 X)

# 다음 릴스에 재사용하는 법
- 위 7단계 흐름 + 캡컷 Adam 적용법은 모든 릴스 동일
- 대본만 콘티별로 갈아끼우면 됨 (창업자 고백/비포애프터/정보형/티저)
- 각 영상 발행 후 3일째 지표(저장·공유·완주·댓글) 기록 → 어떤 콘티가 먹히는지 비교
