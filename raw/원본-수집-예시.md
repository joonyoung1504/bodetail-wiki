# raw/ 폴더 사용법

이 폴더는 **정리 전 원본 자료**를 보관하는 곳이다.  
가공·분류하기 전에 일단 여기에 던져두면 된다.

## 이런 내용을 여기에 저장한다

- 거래처 이메일 원문
- 회의 중 메모 스크랩
- 카카오톡 대화 캡처 내용
- 유용한 기사·리포트 발췌
- 아직 어느 폴더에 넣을지 모르겠는 자료

## 정리 방법

아래 명령으로 LLM에게 정리를 요청한다.

```
/query raw/ 폴더의 미정리 노트를 분류하고 적절한 폴더로 옮겨줘.
```

LLM이 각 노트를 읽고 `product/`, `brand/`, `market/`, `ops/`, `decisions/` 중 적합한 폴더로 이동시키며 frontmatter를 보완한다.

## 보존 원칙

- 원본 텍스트는 절대 삭제하지 않는다.
- 정리 후 이 폴더에서 제거하더라도 해당 폴더의 노트에 원본 출처를 `> 출처: raw/파일명` 형식으로 남긴다.
- 30일 이상 머문 노트는 `/lint` 실행 시 정리 촉구 알림이 뜬다.
