# OEM 업체 협의 현황

## 라온하제 (laonhase.com) ★ 현 1순위
- 롤온 충진·조립 **자사 일괄** (확답) — 분업 안 함
- MOQ: 총중량 약 30kg 기준 → 10ml 3,000개 / 5ml 6,000개 / **20ml 1,500개**
  (원래 5,000개부터인데 최소치로 깎아줌)
- 샘플: 22만원 (최초+수정1회=총 2번, 약 2주)
- 무수 오일 처방 제안
- "닿아도 아프지 않을 만큼 순한" 표현 양산 시 재검토 조건부 가능
- 단가: 처방·용기 확정 후 산출 (아직 미정)
- **잠정 결정: 라온하제 20ml 1,500개** (롤온 일괄, MOQ 최소, 재고 리스크 절반)

## 에이티바이오제약 (atbiopharm@naver.com) — 2순위(펜팁/스포이드)
- 견적 받음 (매니큐어 10ml, 스포이드 50ml)
  - 10ml 매니큐어: 5,000개=개당 2,075원(총 1,037만) / 10,000개=1,637원
  - 50ml 스포이드: 1,000개=5,566원 / 3,000개=3,740원
- 부자재(용기·단상자·박스·디자인)가 단가 37% 차지
- 롤온 아직 미확답(용기 샘플 보내야), 충진업체 연결 거부
- 실리콘팁(펜팁) 수배 중
- 제약사라 품질 신뢰. 리드타임 3개월+
- 롤온 견적 없음 → 롤온 공병 샘플 보내야 비교 가능

## 유스팩토리 (yousssfactory.com) — 2순위
- 초도 100~500개 소량 가능
- 개발의뢰서(PRODUCTPLAN) + 유사 용기 이미지 필수
- 견적·MOQ는 용기 스펙 확정 후

## 에스코스랩 (escoslab.seoul@gmail.com) — 회신 대기
- MOQ 100개·1:1 단독처방·세럼/오일 전문
- 1순위 적합 (소량 검증용)

## 핵심 현실
- 원료 MOQ는 낮으나 용기 MOQ가 높음 → "말만 소량" 많음
- 3~5곳 동시 문의 필요
- 다음 행동: 롤온 공병 사서 에이티바이오에 보내기 / 라온하제 샘플 진행 / 에스코스랩 회신 대기
