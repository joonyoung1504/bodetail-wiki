# 콜라보 전략 (Brand Collaboration)

타깃이 겹치는 소규모 남성 D2C 브랜드와 교차 홍보·번들 구성으로 팔로워와 객단가를 동시에 키우는 전략.

- 우선 타깃: 국내 소규모 D2C 브랜드 (협업 의향 높음)
- 초기 효과: 팔로워 교환 (팔로워 0 탈출에 효과적)
- 수익 구조: 위탁 수수료형(A) / 매입 재판매형(B) / 번들 세트형(C·권장)
- 첫 콜라보 타깃: 이글립스(구강 케어, EP3 입술과 연결)
