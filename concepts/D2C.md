# D2C (Direct-to-Consumer)

중간 유통 없이 브랜드가 소비자에게 직접 판매하는 방식.

- 바디테일 1단계: 자사몰·스마트스토어 D2C
- 장점: 고마진, 고객 데이터 직접 확보, 재구매 관리 용이
- APR 성공 방식과 동일 — D2C 데이터 확보가 핵심
