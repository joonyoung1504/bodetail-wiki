# 이달의 디테일 픽 (Monthly Detail Pick)

- 운영: 매월 1일 발표(인스타 예고) → 말일까지 할인 판매 → 다음 달 교체
- 효과: 고객 재방문율 상승 + 콜라보 브랜드 팔로워 유입 + 릴스 소재 자동 생성
