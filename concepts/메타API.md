# 메타 API (Meta / Instagram Graph API)

인스타그램 비즈니스 계정의 게시물 성과 지표를 자동으로 수집하는 API.

- 제공 지표: views, reach, saved, shares, reels_skip_rate
- 미제공 (수동 입력): 3초 잔존율, 구간 이탈, 도달출처 세부
- **조건**: 팔로워 1,000명+ 비즈니스/크리에이터 계정 전환 후 활성화
- 현재 상태: 미연동 (수동 입력 중)
