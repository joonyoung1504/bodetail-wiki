# Adam TTS (CapCut 샤갈 목소리)

CapCut의 남성 텍스트 음성 변환(TTS) 모델 Adam.

- 외국인이 국어책 읽는 듯한 유행 톤 ("샤갈 톤")
- **설정**: 속도 1.2배 (더 트렌디하고 찰지게)
- 문장을 짧게 끊어야 "툭툭" 끊기는 맛이 삼
- 바디테일 계정 시그니처 목소리로 사용
