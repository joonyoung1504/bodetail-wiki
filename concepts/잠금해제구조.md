# 잠금해제 구조 (Netflix-style Unlock)

다음 EP 제품을 잠금 상태로 예고만 노출해 "다음 편 언제 나와요?"를 유도하는 마케팅 구조.

- EP1 출시 → EP2~EP4는 🔒로만 표시
- 릴스 마지막 컷에 "EP2는 언제?" 자막 삽입
- 댓글 반응 → 힌트 하나씩 공개 → 기대감 증폭
- EP2 출시 시 "EP1 구매자 먼저 알림" → 기존 고객 재구매 자동 유도
