# 벤더 독점 직수출

각국 K-뷰티 전문 유통 벤더와 독점계약을 맺어 현지 판매를 위탁하는 수출 방식.

- 벤더가 현지 마케팅·매대·가격 관리까지 담당 → 우리는 제품·브랜드 집중
- 광고비 0, 재고 리스크 벤더 흡수
- 전제: 국내에서 수요가 이미 증명된 제품이어야 벤더가 관심
- 바디테일 **3단계** 전략 (2~3년차)
