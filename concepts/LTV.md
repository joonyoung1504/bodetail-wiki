# LTV (Lifetime Value / 고객생애가치)

고객 1인이 평생 구매하는 총액.

- 재구매 4회 가정 기준: ₩64,000+
- LTV > CAC 구조가 지속 가능한 비즈니스의 조건
- 재구매 기반 LTV가 높을수록 M&A 멀티플도 높아짐
