# 품질 3테스트

게시물이 "누구나 아는 얘기"가 되는 걸 막기 위해 생성 프롬프트에 상수로 삽입한 3단 필터.

- **검색테스트**: 누구나 아는 말이면 탈락
- **구체성테스트**: 수치·메커니즘·조건분기·성분명 중 최소 2개 포함
- **그래서어떻게테스트**: 현상 지적만 하고 끝내면 금지, 행동까지 제시해야 함
