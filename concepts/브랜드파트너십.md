# 브랜드 파트너십 (Brand Partnership)

타깃이 겹치는 남성 D2C 브랜드 간 교차 홍보·위탁 판매·번들 협력.

- 초기 효과: 인스타 팔로워 교환 → 팔로워 0 탈출 수단
- 협업 대상: 소규모 D2C일수록 의향 높음 (이글립스, 국내 니플패치 브랜드 등)
- 형태: 교차 태그·스토리 공유 / 이달의 픽 위탁 / 번들 세트 구성
- 네일샵 제휴([[네일샵제휴]])와 다른 점: 브랜드↔브랜드 협력 (B2B 파트너십)
