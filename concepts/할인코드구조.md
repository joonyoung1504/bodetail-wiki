# 할인코드 구조 (Affiliate Discount Code)

샵별 고유 코드를 발급해 판매 귀속을 추적하고, 월말 소개비를 자동 정산하는 구조.

- 바디테일 적용: 샵명 기반 코드 (RIBBONY, BITDAM, CLOUD 등)
- 고객에게 3,000원 할인 → 구매 전환율 상승
- 코드별 판매수 자동 집계 → 원장에게 5,000원×횟수 월말 입금
- 위조 불가 이유: 돈이 우리 스마트스토어로 직접 들어옴
