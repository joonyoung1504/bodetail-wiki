# 4겹 해자 (경쟁 방어막)

바디테일의 경쟁자 진입 장벽 4개 레이어.

| 레이어 | 내용 | 방어 강도 |
|--------|------|---------|
| L1 살롱 출처 | 리버니 운영 살롱이 만든 제품 — 진짜 샵·손·결과 | 중 |
| L2 독점 처방 | 실사용 데이터 기반 OEM 독점 처방 | 높음 |
| L3 관계 | 매장→집 루틴→구독 감정적 충성 | 높음 |
| L4 데이터 복리 | 비포애프터·후기·재구매 데이터 라이브러리 | 높음 |
