# A/B 실험 (Split Test)

두 가지 버전 중 하나의 변수만 바꾸어 성과를 비교하는 실험 방식.

- **핵심 규칙**: 한 번에 변수 하나만. 나머지는 고정.
- 실험 순서: T1(주제·훅) → T2(포맷·길이) → T3(자막·BGM) → T4(CTA·시각)
- 1개 영상으로 승자 단정 금지 (표본 ≥5 참고, ≥10 신뢰)
