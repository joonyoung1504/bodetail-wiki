# 네일샵 제휴 (Nail Salon Partnership)

[[BFRB]] 물어뜯는 손톱 교정을 전문으로 하는 네일샵을 오프라인 접점 채널로 활용하는 전략.

- 핵심 로직: 시술 후 홈케어 제품을 자연스럽게 권유 → 고객이 직접 결제 → [[위탁판매]] 구조
- 타깃 샵 조건: 물어뜯는 손톱 포스팅 3개 이상, 팔로워 500명+, 남성 고객 있으면 최우선
- 실제 확인 샵: 빛담네일(부산 서면), 클라우드네일(인천 주안)
- 파일럿 목표: 5개 샵 테스트 → 잘 팔리는 샵 집중 → 3개월 내 30개 샵
