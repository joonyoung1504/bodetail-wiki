# 콘텐츠 반응 생기면 할 것들

## 언제 이 파일을 쓰나
- 릴스 3개 이상 발행 후
- 첫 반응 데이터(저장·공유·완주·댓글)가 쌓인 후
- 팔로워 100명 돌파 후

---

## STEP 1 — 발행 직후 (1시간 내) 기록

릴스 올리고 1시간 뒤 클로드 코드에:
```
content/콘텐츠-성과-DB.md에 오늘 발행한 릴스 기록 추가해줘.
제목: [영상 제목]
hook_type: [반전투표|고백|정보형 등]
발행시간: [HH:MM]
1시간 조회: [숫자]
1시간 저장: [숫자]
특이사항: [없음 or 메모]
git push까지 자동으로.
```

---

## STEP 2 — 발행 3일 후 지표 기록

```
content/콘텐츠-성과-DB.md에 [영상 제목] 3일 지표 업데이트해줘.
reach: [숫자]
saves: [숫자]
shares: [숫자]
completion_rate: [0.xx]
follows_from_post: [숫자]
comments: [숫자]
git push까지.
```

---

## STEP 3 — 10개 쌓이면 패턴 분석

```
content/콘텐츠-성과-DB.md 전체 읽고 분석해줘.
1. 저장률 TOP3 콘텐츠의 공통점 (hook_type, 발행시간, 자막 스타일)
2. 완주율 TOP3 공통점
3. 팔로우 전환율 가장 높은 콘텐츠 특징
4. 아직 검증 안 된 변수 목록
5. 다음 릴스 3개 추천 (이긴 패턴 기반)
결과를 concepts/성공패턴-[날짜].md 로 저장하고 git push.
```

---

## STEP 4 — 대기자 명단 생기면

```
대기자 명단 [숫자]명 확보됐어.
ops/대기자-현황.md 만들어줘.
- 수집 날짜:
- 총 인원:
- 유입 경로 (어떤 릴스에서 왔는지):
- 선호 설문 결과:
- 예상 초도 판매량:
concepts/수요검증의 Open Questions 업데이트하고 git push.
```

---

## STEP 5 — 팔로워 1000명 넘으면 (메타 API 연동)

```
메타 API 자동 수집 스크립트 만들어줘.
config/secrets.env에서 토큰·계정ID 읽어와서
모든 content/ 릴스 노트의 지표 필드를 자동 갱신.
1시간마다 자동 실행되게 cron 설정.
git push까지.
```

---

## 이 사람 방법 중 데이터 생기면 추가 적용할 것

### 콘텐츠 패턴 JSON 구조화
릴스 10개 쌓이면 각 영상을 JSON으로 구조화해서 concepts/ 에 저장.
어떤 변수 조합이 이겼는지 AI가 패턴을 찾아줌.

```
content/콘텐츠-성과-DB.md 읽고
각 릴스를 릴스-콘티-템플릿.md의 JSON 형식으로 변환해서
content/릴스-[번호]-[제목].json 으로 저장해줘.
저장 완료 후 "어떤 hook_type이 평균 저장률 가장 높았는지" 분석해줘.
git push까지.
```

### 인스타 댓글 지식화
"저요", "나도", "남친한테 보여줌" 같은 댓글 패턴을 concepts/댓글패턴.md에 정리.
이게 쌓이면 타깃 심리를 정확히 이해할 수 있음.

```
오늘 릴스 댓글 패턴을 concepts/댓글패턴.md에 추가해줘.
영상: [제목]
공감형 댓글: [예시들]
질문형 댓글: [예시들]
공유 의도 댓글: [예시들]
부정 댓글: [예시들]
인사이트: [이 패턴에서 읽히는 것]
git push까지.
```
