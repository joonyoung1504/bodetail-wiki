# 데일리 포스트 생성기 (generate_daily_post.py)

> 출처: [[raw/2026-07~08_사지방기간_전체기록]] §2. 사지방 기간(2026-07~08) 동안 GitHub Actions 기반으로
> 구축한 게시물 자동 생성 시스템. [[marketing_auto/MA_03_automation_structure]]에서 구상만 하던
> "클로드 코드 + 자동화" 계획이 실제로 이 형태로 구현됐다.

## 주제 순환 시스템

- **버그 #1 (최초)**: 미래 날짜(`2026-09-15`)를 기준일로 잡아 경과일 계산이 항상 0/음수 → 주제가 매일 반복.
- **해결**: 날짜 계산 폐기, `posts/topic_state.json`에 `last_day` 저장 후 매 실행 `(last_day % total) + 1`로 순환.
- `day_override`: 상태 파일 안 건드리고 특정 번호만 재생성(수동 재생성용).
- 30일 배치 소진 시 `refresh_topics_batch()`가 다음 배치를 자동 생성. 실패해도 기존 배치로 안전 재순환.
- 범위 밖 DAY 번호 입력 시 조용히 DAY1로 폴백하던 버그 → 자동 순환 매핑 + 경고 로그로 수정.
- 커스텀 주제 입력(`custom_topic`/`custom_desc`/`custom_section`) 지원 — 비우면 자동 순환, 채우면 SPECIAL 표기로 그날만 대체.

## 품질 문제와 3단계 해결

"누구나 아는 얘기다, 꿀팁이 아니다"라는 지적에서 시작.

1. **품질 3테스트** (프롬프트 상수로 삽입): 검색테스트(뻔한 말 탈락) / 구체성테스트(수치·메커니즘·조건분기·성분명 중 최소 2개) / 그래서어떻게테스트(현상지적 금지, 행동까지)
2. **content_brief 필드**: 각 주제에 "그날 반드시 다룰 구체 항목" 100자 지시문 — 품질을 실제로 끌어올리는 핵심 장치
3. **topic_domains.md**: 사람이 직접 편집하는 12개 분야 소재 사전(클렌징·자외선·기초케어·고민별·헤어·체취·운동장비/불균형·생활습관·상황 등). 배치 소진 시 이 파일을 읽어 다음 배치 자동 생성.

## 주제 생성 공식 (topic_formula.md)

벤치마크 계정(@iamtheserkan, @minens.mag — [[content/벤치마크-세르칸-미넨스]])의 좋은 주제들을 역분석해서 도출.

- **주제 해부학 5요소**: 분해 축 / 수치 앵커 / 혼동 지점 / 실행 종결 / 오답 제거
- **[[콘텐츠원형]] A1~A15**: 15개 원형(분류→처방, 혼동해소, 파라미터 완전정복, 랭킹·티어, 습관→개선메커니즘 등)
- **제목 창의성 패턴 8종**: 제약선언·연쇄화살표·등식·신조어·상황극단·등급차수·역설·숫자+정체성
- **배치 구성 규칙**: 최소 9개 원형 등장, 같은 원형 5개 초과 금지, A5·A8·A11·A15 배치당 최소 1개 필수
- 이 공식으로 주제 배치가 30일 → 42일 → 60일 → 66일로 확장됨

## 다음 편 예고

- 마지막 페이지에 실제 다음 날짜 주제를 조회해 정확히 주입(지어내지 않음). 캡션에도 자동 추가.
- 주제 순서를 연관 클러스터(원리→진단→처방→비교→추천)로 재배열해 예고가 자연스럽게 이어지도록 함.
- **버그**: `post_json`에 `next_preview` 필드가 최상위에만 있어 에디터에 안 뜸 → 최상위 + 마무리 슬라이드 양쪽 중복 삽입으로 해결.
- **미해결 (INV급 이슈)**: DAY1 예고 제목과 실제 DAY2 표지 문구가 다름. 원인은 Claude가 표지 headline을 자기 마음대로 재작성해서. 합의된 해법(A안): headline을 `title_main`으로 고정, 부제만 생성 — **코드 미반영**.

## 레이아웃/가독성

- 분량 상한 도입: 소제목 18자 1줄, 본문 정확히 2줄×26자, 1줄=사실/2줄=행동, "—" 문장잇기 금지
- **비교 기준은 절대 압축에서 버리면 안 됨**: "여성보다" 같은 비교기준을 빼면 문장이 이해 불가 → "절대 버리면 안 되는 것"(비교기준·수치·조건·행동동사) vs "버려야 하는 것"(수식어·접속) 리스트화
- 텍스트 하단 정렬 렌더러 개편 — 자세한 함정은 [[content/편집기-진화-렌더러함정]] 참조

## PICK 게시물 가격 정확도

"약 2만원대" 같은 어림 표기가 실제로는 Claude 학습 기억으로 대충 쓴 것으로 판명 → PICK 게시물 생성 시에만 웹서치 도구를 붙여 실제 올리브영 판매가 검색 후 작성, 확인 못하면 다른 제품으로 교체.

## 학습 루프 (규칙 증류)

- `fetch_ig_insights.py`: 인스타 Graph API로 게시물별 반응(좋아요·저장·도달) 수집. **로그인 스크래핑은 메타 약관 위반+계정정지 위험이라 명시적으로 배제, 공식 API만 사용.**
- `learn_from_results.py`: 반응 데이터 + 최근 게시물 + 기존 규칙을 분석해 `content/learnings.md`를 통째로 재작성(검증된 규칙/검증중/폐기). 다음날 생성 프롬프트에 자동 주입.
- `weekly_learn.yml`로 매주 일요일 실행.

## 미해결 이슈 (2번째)

워터마크 박힌 스톡이미지, 의학 일러스트풍 이미지가 게시물에 섞여 나온 사례 발견(살구색 피부단면도, Adobe Stock 워터마크). 브랜드 톤(잉크블랙·크림·골드 다크무드)과 이질적. **원인 미확정**(수동 삽입 vs 자동 생성) — 코드 수정 안 됨.
