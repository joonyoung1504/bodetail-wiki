# 인스타 실무 지표 완전 해석 가이드

## 원칙 — 지표를 보는 순서
초보: 좋아요만 봄
중급: 저장·도달·팔로워 봄
실무: 아래 4그룹을 순서대로 봄

---

## 그룹 A — 알고리즘 핵심 (노출 직결)

### saves 저장수
- **의미**: "다시 볼 가치 있다" 신호. 알고리즘이 가장 강하게 보는 지표
- **목표**: save_rate(저장수÷도달) 4% 이상
- **해석**: 4% 미만이면 콘텐츠 자체에 "보관할 이유"가 없음 → 정보·팁·공감 요소 부족
- **올리는 법**: "저장해두세요" CTA 명시, 정보형·리스트형, 나중에 쓸 것 같은 느낌

### shares 공유수 + sends_dm DM 전송
- **의미**: "친구에게 보낼 만하다" = 바이럴 엔진. 저장보다 더 강한 도달 신호
- **해석**: DM 전송이 많으면 공감도 최고. "내 친구 얘기 같다" 또는 "이거 봐라"류
- **올리는 법**: 길거리 투표·반전·공감 콘텐츠

### completion_rate 완주율
- **의미**: 끝까지 본 비율. 릴스 핵심 지표
- **목표**: 60% 이상이면 우수
- **해석**: 낮으면 → drop_off_point(이탈 시점) 확인. 거기서 영상이 지루해짐
- **올리는 법**: 끝에 반전·결론 배치, "끝까지 봐야 알 수 있음" 구조

### avg_watch_time 평균 시청 시간
- **의미**: 평균 몇 초 봤나. 영상 길이 대비 비율로 봐야 함
- **해석**: 15초 영상에서 12초 = 우수 / 3초 영상에서 5초 = 반복 시청(루프)

### rewatch_rate 재시청률
- **의미**: 다시 본 비율. 루프되는 영상 = 알고리즘이 매우 좋아함
- **올리는 법**: 끝 장면이 처음 장면으로 자연스럽게 연결되게 편집

## 그룹 B — 초기 반응 (1시간이 전부)

### views_1h 발행 후 1시간 조회수
- **의미**: 알고리즘 부스팅 여부 결정. 1시간 내 반응이 좋으면 더 많이 뿌려줌
- **목표**: 팔로워 수 대비 30~50% 이상이면 좋음 (팔로워 100명이면 30~50뷰)
- **해석**: 1시간 조회가 느리면 → 발행 시간이 잘못됐거나 초반 훅이 약함

### saverate_1h 1시간 내 저장률
- **의미**: 가장 예측력 높은 초기 신호. 1시간 저장률이 높으면 떡상 예측
- **목표**: 1시간 내 저장률 3% 이상이면 주목
- **해석**: 1시간 저장률이 낮은데 나중에 터지는 경우는 드묾

### eng_velocity 반응 속도
- **의미**: 발행 직후 단위시간당 (좋아요+저장+댓글)의 속도
- **해석**: 속도가 빠를수록 알고리즘이 "이거 핫한데?" 인식

### first_hour_reach 1시간 내 도달
- **의미**: 팔로워에게만 뿌려진 건지 비팔로워에게도 퍼졌는지 확인
- **해석**: 1시간 도달이 팔로워 수보다 훨씬 크면 → 탐색 탭에 이미 올라간 것

## 그룹 C — 도달·성장 (어디서 왔나)

### reach vs impressions
- reach = 영상을 본 계정 수 (사람 수)
- impressions = 총 노출 수 (한 사람이 3번 보면 impressions=3, reach=1)
- **해석**: impressions ÷ reach > 1.5면 재시청 많음 = 좋은 신호

### reach_follower vs reach_nonfollower
- **의미**: 팔로워 도달 vs 비팔로워 도달 비율
- **해석**: 비팔로워 비율이 60%+ 이면 탐색·릴스탭에서 신규 유입 중 = 성장 신호

### 도달 출처 (source_*)
| 출처 | 의미 | 해석 |
|---|---|---|
| source_reels | 릴스탭에서 옴 | 알고리즘이 밀어주는 중 |
| source_explore | 탐색 탭 | 바이럴 시작 신호 |
| source_home | 팔로워 홈피드 | 기존 팬이 봄 |
| source_hashtag | 해시태그 검색 | 해시태그 전략이 먹힘 |
| source_audio | 음원 검색 | 유행 음원 잘 탄 것 |
| source_profile | 프로필 방문 후 봄 | 콘텐츠가 프로필 탐색 유도 |

- **핵심**: source_reels + source_explore가 높을수록 알고리즘이 밀어주는 것

### follows_from_post 게시물 → 팔로우 전환
- **의미**: 이 영상 보고 팔로우한 수
- **목표**: 도달 1,000명당 5명 이상이면 우수
- **해석**: 낮으면 → 프로필이 약하거나 "왜 팔로우해야 하는지" 이유가 없음

### profile_visit_rate 프로필 방문율
- **의미**: 영상 본 사람 중 프로필 클릭한 비율
- **목표**: 3~5% 이상
- **해석**: 낮으면 → 프로필 클릭 CTA가 없거나 콘텐츠와 계정 연결이 약함

### link_clicks 링크 클릭 + sticker_taps 스티커 탭
- **의미**: 대기자 폼·자사몰로 이동한 수. 직접 전환 추적 지표
- **해석**: 이게 최종 목표. 링크클릭 ÷ 도달 = 전환율

## 그룹 D — 진단 (왜 이탈했나)

### hook_retention_3s 3초 잔존율
- **의미**: 첫 3초 이후에도 남은 비율. 훅이 먹혔는지 판단
- **목표**: 70% 이상
- **해석**: 낮으면 → 첫 자막·첫 장면을 바꿔야 함. 가장 먼저 고쳐야 할 부분

### drop_off_point 최대 이탈 시점
- **의미**: 가장 많이 이탈한 초(秒)
- **해석**: 그 장면을 찾아서 왜 지루한지 분석 → 다음 영상에서 그 구간 수정

### save_to_reach / share_to_reach
- **의미**: 도달 대비 저장·공유 비율 (품질 정규화 지표)
- **해석**: 도달이 많아도 저장률이 낮으면 "그냥 지나친 것". 비율로 봐야 진짜 품질

### retention_curve 이탈 곡선
- **의미**: 구간별 시청자가 얼마나 남았나 (앱 인사이트에서 그래프로 확인)
- **해석**: 급격히 꺾이는 구간 = 거기서 편집·내용이 약함

## 발행 후 체크 루틴 (실무 타이밍)

| 시점 | 볼 것 | 판단 |
|---|---|---|
| 발행 직후 1시간 | views_1h, saverate_1h, first_hour_reach | 떡상 여부 초기 판단 |
| 발행 후 24시간 | reach_nonfollower 비율, source_reels/explore | 알고리즘 탔나 확인 |
| 발행 후 3일 | save_to_reach, completion_rate, follows_from_post | 콘텐츠 품질 최종 판단 |
| 발행 후 7일 | link_clicks, 대기자 폼 유입 수 | 전환 성과 |

## 이상치 처리 (노이즈 제거)

- 성과가 평균의 3배 이상이면 → `anomaly_note` 기록 (인플루언서 공유 등 외부요인)
- 이상치는 성공방정식 계산에서 제외하거나 별도 분석
- 표본 5개 미만 → 참고용만 / 10개 이상 → 신뢰
