# 마케팅 자동화 구조 + 클로드-캡컷 연동

## 전체 자동화 구조

```
[클로드 AI (나)] → 기획·대본·콘티·명세서 생성
        ↓
[클로드 코드] → 명세서 읽고 캡컷 자동화 스크립트 실행
        ↓
[캡컷] → 영상 자동 생성·편집
        ↓
[준영] → 완성 영상 받아서 인스타 업로드만
        ↓
[메타 API] → 성과 지표 자동 수집 (팔로워 1,000명 후)
        ↓
[옵시디언 위키] → 지표 자동 기록·분석·다음 콘티 반영
```

---

## 클로드 AI vs 클로드 코드 — 언제 뭘 쓰나

| 작업 | 클로드 AI (이 대화) | 클로드 코드 (터미널) |
|---|---|---|
| 콘티·대본 기획 | ✅ 여기서 | ❌ |
| 지표 해석·전략 판단 | ✅ 여기서 | ❌ |
| 외부 시장 정보 검색 | ✅ 여기서 | ❌ |
| 파일 생성·위키 정리 | ❌ | ✅ 클로드 코드 |
| 캡컷 자동화 스크립트 실행 | ❌ | ✅ 클로드 코드 |
| 지표 수집·DB 업데이트 | ❌ | ✅ 클로드 코드 |

**핵심**: 기획은 나(클로드 AI)한테, 실행·자동화는 클로드 코드로.

---

## 1단계 현재 (수동 편집)

### 흐름
1. 클로드 AI → 완성 제작 명세서 생성 (대본+타이밍+효과 전부)
2. 준영 씨 → 명세서 보고 캡컷에서 수동 제작
3. 발행 후 지표 수집 → 위키에 수동 기록
4. 다음 콘티 반영

### 제작 명세서 포맷 (클로드 AI가 생성)
```
[영상 기본]
- 길이: 13초
- 비율: 9:16
- 해상도: 1080p

[소스 파일]
- 0~7초: before.jpg (거친 손톱)
- 7~13초: after.jpg (깔끔한 손톱)

[자막 타이밍]
- 0.0~1.5s: "이성을 볼 때" | 흰색 Bold | 중앙
- 1.5~3.0s: "의외로 가장 신경 쓰이는" | 흰색 Bold | 중앙
...

[TTS]
- 음성: Adam (캡컷) / 속도: 1.2
- 각 자막과 동일 타이밍

[BGM]
- 0~7초: dramatic/tense (캡컷 무료)
- 7~13초: 밝은 전환

[전환]
- 7초 지점: 슬라이드 0.5초

[효과음]
- 3초: "딩!" (포인트)
```

## 2단계 (나중에 — 클로드 코드 + 캡컷 자동화)

### 방법 A: 캡컷 웹 자동화 (Playwright/Selenium)
클로드 코드가 브라우저를 직접 조작해서 캡컷 웹에서 영상 제작

```python
# 클로드 코드가 생성하는 스크립트 예시
from playwright.sync_api import sync_playwright

def make_reels(명세서):
    with sync_playwright() as p:
        browser = p.chromium.launch()
        page = browser.new_page()
        page.goto("https://capcut.com")
        # 로그인 → 새 프로젝트 → 소스 업로드
        # → 자막 추가 → TTS Adam → 내보내기
        ...
```

**장점**: 완전 자동화 가능
**단점**: 캡컷 UI가 바뀌면 스크립트 수정 필요, 안정성 낮음

### 방법 B: CapCut API (공식, 현재 기업용)
- 현재 캡컷 공식 API는 기업(비즈니스) 대상
- 개인에게는 아직 열리지 않음
- 2026년 하반기 중 확대 가능성 있음

### 방법 C: ffmpeg + 파이썬 자동화 (지금 바로 가능)
클로드 코드가 ffmpeg로 직접 영상을 만들고, 자막·BGM·전환을 코드로 합성

```bash
# 자막+BGM+이미지를 합쳐 영상 생성
ffmpeg -i before.jpg -i after.jpg -i bgm.mp3 \
  -vf "drawtext=text='이성을 볼 때':fontsize=60:fontcolor=white" \
  output.mp4
```

**장점**: 지금 당장 가능, 안정적
**단점**: 고급 효과(캡컷 고유 애니메이션)는 제한적

### 현실 추천 순서
1. 지금: 클로드 AI 명세서 → 준영 씨 수동 캡컷 (1~2개월)
2. 콘텐츠 패턴 나오면: ffmpeg 자동화 스크립트 클로드 코드로 제작
3. 팔로워 1,000명+: 메타 API 연동
4. 영상 패턴 완전히 정형화되면: Playwright로 캡컷 자동화 시도

## 3단계 완성형 자동화 (목표)

### 전체 자동화 루프
```
매주 월요일 9시 자동 실행:

1. 클로드 코드 → 지난주 지표 분석
2. 위키의 validated Insight 읽기
3. 이긴 변수 조합으로 이번 주 콘티 3개 생성
4. ffmpeg 또는 캡컷으로 영상 자동 제작
5. 영상 파일 준영 씨 폰으로 전송
6. 준영 씨 → 인스타 업로드 (1분)
7. 발행 후 1시간: 메타 API로 초기 지표 수집
8. 위키 업데이트 → 다음 주 반영
```

## 릴스 제작 명세서 자동 생성 요청 방법

클로드 AI (이 대화)에 이렇게 요청:

```
이번 릴스 명세서 만들어줘.
소재: [이번 영상 주제]
이미지: [어떤 사진 갖고 있는지]
길이: [몇 초짜리]
목표 반응: [저장/댓글/공유 중 뭐]
```

→ 클로드가 대본·타이밍·효과·TTS·BGM·해시태그·캡션·첫댓글까지 다 만들어줌
→ 그걸 들고 캡컷에서 따라 만들면 됨
