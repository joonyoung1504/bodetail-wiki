# 바이럴 릴스 완전 공략집

## 1. 훅(Hook) — 첫 3초가 전부

### 심리 트리거 7가지
| 트리거 | 예시 | 반응 유형 |
|---|---|---|
| 호기심 결핍 | "남자 손톱… 이렇게까지 신경 쓸 일인가?" | 완주 |
| 반전 예고 | "당신이 모르는 첫인상의 비밀" | 완주 |
| 수치·순위 | "이성이 신경 쓰는 신체 1위는?" | 저장 |
| 공감 자극 | "손톱 뜯는 사람 손들어" | 댓글 |
| 금지·비밀 | "90%가 모르는 손끝 관리법" | 저장·공유 |
| 직접 지목 | "손 자신 없는 사람 이거 봐" | 저장 |
| 긴급성 | "지금 당장 손톱 봐봐" | 반응 속도 |

### 훅 자막 공식
```
[타깃 지목] + [궁금증/반전] + [숫자 또는 희소성]
예: "손톱 뜯는 사람만 아는 것 3가지"
예: "90%가 모르는 첫인상의 진실"
예: "이성이 의외로 제일 먼저 보는 곳"
```

### 금지 패턴
- "안녕하세요 저는~" 으로 시작 → 즉시 이탈
- 첫 3초에 로고·인트로 → 이탈
- 말이 느린 도입부 → 이탈

## 2. 자막 심리학 — 쓰는 것만큼 안 쓰는 게 중요

### 클릭·저장 유도 자극어 목록
```
호기심: "아는 사람만 알지만" / "알사람은 다 알지만" / "솔직히 말하면" / "실제로는"
희소성: "90%가 모름" / "아무도 안 알려주는" / "이것만 알면" / "딱 한 가지"
공감: "혹시 나만?" / "이 경험 있으면 좋아요" / "손 들어봐" / "저요"
반전: "생각보다" / "의외로" / "근데" / "사실은"
긴급: "지금 당장" / "오늘부터" / "이거 하나만"
```

### 자막 스타일 (일관성 유지)
- **폰트**: 굵은 고딕 계열 (Pretendard Bold, 나눔 스퀘어 ExtraBold)
- **색상**: 흰색 기본 + 강조는 노란색 또는 옥스블러드(#6B1620)
- **테두리(윤곽선)**: 검은색 2~3px (어떤 배경에서도 가독성)
- **크기**: 화면 너비 70~80%
- **위치**: 화면 중앙 또는 하단 30% (상단은 인스타 UI에 가림)
- **애니메이션**: 팝업 또는 타이핑 효과 (캡컷 기본 제공)

### 자막 길이 공식
- 한 자막에 최대 10~15자 (짧게 끊어야 샤갈 맛)
- 문장을 2~3개로 쪼개기: "의외로" → "손톱을" → "많이 본다" (끊기는 맛)

## 3. 편집 리듬 — 지루하면 이탈

### 컷 속도
- P1 초기: 빠른 컷 (1~2초마다)
- 감정 고조 구간: 느린 컷으로 전환
- 반전 순간: 정지 → 빠른 컷

### BGM 전략
| 구간 | BGM | 효과 |
|---|---|---|
| 훅(0~3초) | 두구두구/긴장감 | 궁금증 증폭 |
| 전개 | 잔잔하지만 집중 | 내용 전달 |
| 반전/결론 | 밝게 전환 | 감정 해소 |
| CTA | 조용하게 | 행동 유도 |

### 효과음 활용
- "딩!" 소리: 포인트 자막 등장 시
- 타이핑 소리: 텍스트 나올 때
- 두구두구: 반전 직전

### 전환 효과 (캡컷)
- 빠른 슬라이드: 비포→애프터
- 줌인: 클로즈업 포인트
- 페이드: 감성 구간

## 4. CTA 공식 — 원하는 반응을 설계

### 목표별 CTA
| 목표 | CTA 문구 | 배치 위치 |
|---|---|---|
| 저장 유도 | "나중에 쓸 것 같으면 저장 🔖" | 영상 후반 |
| 댓글 유도 | "당신은? 댓글로 👇" | 영상 끝 |
| 공유 유도 | "이 사람한테 보내줘야지 싶으면 공유" | 반전 직후 |
| 팔로우 유도 | "계속 볼 것 같으면 팔로우" | 영상 끝 |
| 링크 유도 | "출시 알림 받기 → 프로필" | 영상 끝 |

### CTA 금지 패턴
- "좋아요와 구독 부탁드립니다" → 구식, 아무도 안 함
- 모든 CTA 동시에 → 아무것도 안 함
- 맨 앞에 CTA → 알고리즘 패널티 가능

## 5. 해시태그 전략

### 바디테일 기본 해시태그 세트

**세트 A — 손톱/그루밍 메인**
```
#남자손톱 #손톱뜯기 #그루밍 #자기관리 #네일케어 #손끝 #남자그루밍 #손톱관리
```

**세트 B — 바이럴 확산용**
```
#릴스 #인스타그램릴스 #남자 #첫인상 #데일리 #일상
```

**규칙:**
- 총 8~12개 (너무 많으면 스팸으로 인식)
- 대형 태그(1억+) 1~2개 + 중형(100만~1000만) 4~6개 + 소형(10만 이하) 2~4개
- 매 게시물 동일 해시태그 반복 금지 (섀도우밴 위험) → 세트 A/B 번갈아 사용

## 6. 발행 타이밍

### 최적 발행 시간 (한국 기준, 테스트 필요)
| 시간대 | 이유 |
|---|---|
| 오전 7~9시 | 출근 전 스크롤 |
| 점심 12~1시 | 점심시간 |
| 저녁 7~9시 | 퇴근 후 황금시간대 |
| 밤 10~11시 | 자기 전 릴스 |

- **첫 1주**: 여러 시간대 테스트 → views_1h 비교
- **최적 시간 발견 후**: 고정 루틴

### 발행 요일
- **화·수·목**: 조회수 가장 높은 경향
- **월·금**: 중간
- **주말**: 낮은 경향 (단 콘텐츠에 따라 다름)

---

## 7. 첫 댓글 전략

발행 즉시 본인이 첫 댓글 달기:
```
좋은 예: "손 자신 없는 분 댓글로! 저도 솔직히 없었어요 ㅋㅋ"
좋은 예: "여러분은 이성 볼 때 어디 먼저 보나요?"
나쁜 예: "새 영상 올렸어요! 많은 관심 부탁드려요~"
```

첫 댓글이 질문이면 → 댓글 달기 쉬워짐 → 알고리즘 참여 신호

---

## 8. 계정 일관성 (브랜드 시그니처)

### 시각 일관성
- 커버 이미지: 항상 같은 스타일 (텍스트+어두운 배경 or 손 클로즈업)
- 자막 폰트·색상: 항상 동일 (흰색+검은테두리 or 옥스블러드 강조)
- 필터: 없거나 항상 같은 필터

### 톤 일관성
- TTS Adam 목소리 → 계정 시그니처
- 끊기는 자막 리듬 → 인식 가능한 스타일
