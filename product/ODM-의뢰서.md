# ODM 제품 개발 의뢰서 (Product Brief)

> OEM/ODM 공장 미팅·샘플 의뢰 시 공유하는 기본 스펙.  
> 각 업체별 진행 현황 → [[ops/OEM-업체-비교]]

## 제품 개요

| 항목 | 내용 |
|------|------|
| 제품명 (가칭) | 바디테일 BFRB 케어 오일 세럼 |
| 대상 부위 | 손톱·큐티클·주변 살 |
| 주요 타깃 | BFRB(손톱 물어뜯기) 컴플렉스 있는 20~30대 남성 |
| 포지셔닝 | 살롱 전문가가 만든 입문용 셀프 케어 세럼 |

## 제형 스펙

| 항목 | 요구사항 |
|------|---------|
| 제형 방향 | **무수(無水) 드라이 오일 베이스** — 방부제 불필요, 저자극 |
| 점도 | 저~중점도 (롤러볼·펜팁 도포 가능한 묽기) |
| 외관 | 투명 또는 옅은 앰버톤 |
| 향 | 무향 또는 극소 천연향 |
| 알코올 | **무알코올** |

## 희망 성분

| 목적 | 성분 |
|------|------|
| 베이스 오일 | 호호바·아르간·스쿠알란 |
| 피부장벽 | 세라마이드 |
| 진정·재생 | 병풀(시카)·알란토인 |
| 손톱·큐티클 강화 | 케라틴·비오틴·판테놀·비타민E |

## 안전 기준

| 항목 | 기준 |
|------|------|
| 안전 등급 | **입에 닿아도 안전** (영유아·립 수준) |
| 알레르기 | EWG 그린 등급 우선 |
| 자극 | 무알코올·무방부제·무향료 지향 |
| 화장품법 | "치료·완치·회복·소독" 표현 금지 — "보습·케어·관리" |

## 용기 스펙

| 우선순위 | 용기 | 이유 |
|---------|------|------|
| **1순위** | 롤러볼 (Roll-on) 20ml | 손톱·큐티클 조준 도포 + 마사지감. 남성 거부감 최소 |
| 2순위 | 펜팁형 (형광펜식 단단한 팁) | 롤러볼 불가 시 대안 |
| 제외 | 매니큐어 붓형, 스프레이형 | 남성 거부감 / 조준 불가 |

## MOQ·수량 선택지

| 수량 | 용도 |
|------|------|
| 500개 | 최소 검증 (에스코스랩 등 소량 업체) |
| 1,000개 | 표준 런칭 |
| 1,500개 | 라온하제 20ml 기준 최소 발주 |
| 3,000개 | 규모 효율·단가 절감 단계 |

> **10ml vs 20ml 트레이드오프**:  
> 10ml: 재구매 주기 이상적(1~1.5개월), MOQ 3,000개 → 재고 부담  
> 20ml: MOQ 1,500개 → 재고 리스크 절반, 단가 효율 확인 필요

## 독점 처방 조건

- **1사1처방(독점)** 요청: 동일 처방을 타사에 공급하지 않는 조건
- 계약서에 명시 필수
- 이유: [[brand/브랜드-정체성]] 4겹 해자 Layer 2 (독점 처방 = 못 베끼는 강점)

## 샘플 의뢰 시 확인 사항

1. 샘플을 **롤온 형태로** 수령 가능한지 (실사용감 확인)
2. 양산 리드타임 (발주~납품 소요기간)
3. 10ml 3,000개 vs 20ml 1,500개 단가·효율 비교 의견
4. 1사1처방 계약 가능 여부
5. 무수 처방 샘플 제공 가능 여부
