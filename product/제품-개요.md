# 제품 개요 — 바디테일 손톱 케어 오일 세럼

## 제품 포지셔닝
- 카테고리: BFRB(손톱 물어뜯기) 케어 오일 세럼
- 제형: **무수(無水) 드라이 오일 베이스** — 수상+유상 혼재 없음, 방부 불필요, 저자극
- 용량: **20ml (본품)** / 10ml (휴대·입문용 검토 중)
- 색상: 맑은 오일색 (아르간 등 원료 고유색, 완전 투명 불가)
- 향: 무향 또는 극소량 천연향

## 처방 (희망 성분)

| 기능 | 성분 |
|------|------|
| 보습 (베이스) | 호호바오일, 아르간오일, 스쿠알란, 스위트아몬드오일 |
| 보호막 | 세라마이드 |
| 진정 | 병풀추출물(마데카소사이드), 알란토인 |
| 손톱 영양 | 가수분해케라틴, 비오틴, 판테놀, 비타민E(토코페롤) |
| 옵션 | 데나토늄(쓴맛 자각 버전) — 별도 처방 가능(라온하제 확인 필요) |

> 최종 배합비·안전농도는 연구원 판단. 무수 처방 시 수상 성분은 오일 가용 형태로 대체 또는 제외.

## 안전 기준 (최우선)
- 영유아·입술 제품 수준 **초저자극**
- **무알코올**
- 가능한 **EWG 그린 등급**
- "입에 닿아도 아프지 않을 만큼 순한 성분" — 손톱 무는 사용 특성 고려 (양산 시 재검토 조건부)

## 효능 표현 규제 (중요)

| 구분 | 내용 |
|------|------|
| 절대 금지 | 치료, 완치, 소독, 질병, **회복** (라온하제 지적 — 의약품 영역) |
| 허용 | 보습, 관리, 정돈, 영양, 케어 |
| 주의 | 피·열린 상처엔 사용 불가 / 변형 손톱 = "교정 아닌 회복보조" 단정 금지 |

## 용기 결정

| 순위 | 유형 | 이유 |
|------|------|------|
| 1순위 ★ | **롤온(롤러볼)** | 손톱·큐티클 조준 도포 + 마사지감. 충진 구조: 오일→볼압입→캡 |
| 2순위 | 형광펜식 단단한 팁 | 매니큐어 붓 아님 — 남성 거부감 회피 |
| 탈락 | 스프레이 | 조준 불가, 점도 분사막힘, 마사지 없음 |
| 2번 제품 후보 | 밤 타입 | 휴대·보호용으로 별도 검토 |

롤온 위생 규칙: 사용 후 휴지로 닦기 (물세척 X — 무수오일에 수분), 상처엔 볼 직접 접촉 금지.

## 단위 경제 (Unit Economics)

| 항목 | 금액 |
|------|------|
| 소비자가 (잠정) | ₩18,000~22,000 |
| 제조원가 (내용물+용기+단상자, 1,500~3,000개 기준) | ₩2,000~2,800 |
| 기여이익 (마케팅비 전) | ~71% |
| CAC (오가닉 유입 기준 blended) | ≈₩5,500 |
| 첫 구매 순기여 | ≈₩7,300 |
| **손익분기점** | **약 2,000개** (초도 3,000개 중 2/3만 팔면 본전) |
| 1인당 연간 LTV (재구매 4회 가정) | ₩64,000+ |

> 핵심: 재구매 시 CAC ≈ 0 → 기여이익 전액(₩12,800)이 남음. **매출 엔진 = 재구매**.

## 사용 기간 (재구매 주기)
- 10ml: 하루 2~3회 기준 약 1~1.5개월 소진 → 재구매 주기로 이상적
- **본품 20ml 권장 / 10ml = 휴대·입문용**

## 큐티클 오일 시장 내 포지셔닝

| 경쟁 제품 | 빈틈 |
|---------|------|
| OPI 프로스파 (프리미엄·고가) | 비싸고 사용감 무거움 |
| 위드샨 아보카도 (가성비 5입) | 브랜드 경험·향 약함 |
| 슈퍼네일 대용량 (샵 실속) | 휴대·감성 0 |
| ORLY 향 라인 | 손톱 기능보다 향 위주 |

**우리 자리:** "살롱 퀄리티를 데일리 가격에, 롤온 하나로 간편하게."
산뜻한 흡수 + 손톱 영양 성분 + 롤온 애플리케이터 + 살롱 검증 — 이 넷을 동시에 가진 제품이 비어 있음.
