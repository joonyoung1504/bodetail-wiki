# 용기 스펙 — 롤러볼 20ml (확정)

## 결정 요약

| 항목 | 결정 |
|------|------|
| **1순위** | 롤러볼 (Roll-on) **20ml** |
| 2순위 | 펜팁형 (형광펜식 단단한 팁) |
| 제외 | 매니큐어 붓형, 스프레이형 |
| 용량 비교 | 10ml vs 20ml — 라온하제 확인 중 |

## 결정 근거

**롤러볼 1순위 이유**:
- 손톱·큐티클 조준 도포 + 마사지감 동시 제공
- 남성이 매니큐어 붓에 느끼는 거부감 없음
- 휴대·일상 루틴에 자연스럽게 녹아드는 형태 ("호감포인트" 콘텐츠 소재)

**10ml vs 20ml 트레이드오프**:

| | 10ml | **20ml (잠정)** |
|--|------|-------------|
| MOQ (라온하제) | 3,000개 | **1,500개** |
| 재구매 주기 | 1~1.5개월 (이상적) | 2~3개월 |
| 재고 리스크 | 높음 | **절반** |
| 단가 효율 | 높음 | 확인 중 |

→ 초도 재고 리스크를 낮추기 위해 **20ml 1,500개 잠정 선택**. 수요 검증 후 10ml로 전환 가능.

## 용기 기능 요건

- 롤러볼 구름: 0.4~0.6mm 틈새 (저~중점도 무수 오일에 맞는 클리어런스)
- 소재: 투명 또는 스모크 유리/PET
- 뚜껑: 나사식 또는 클릭형 (오일 누출 방지)
- 표면: 라벨 인쇄 또는 직인쇄 (브랜드 컬러 옥스블러드 반영)

## 남성 배려 포인트

- 필통·주머니에 넣을 수 있는 크기 → 롤온 20ml 적합
- 휴대하며 쓰는 것 자체가 "호감포인트" 콘텐츠 소재
- 붓형·스포이드형은 "화장품 느낌" 강해 남성 타깃에 불리
