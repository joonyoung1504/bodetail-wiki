# bodetail 주제 분야 사전 (topic_domains.md)

> **이 파일의 역할**
> 30일 주제 배치가 소진되면 `generate_daily_post.py`가 이 파일을 읽어 다음 배치를 만든다.
> 여기 적힌 분야·소재가 다음 배치의 재료가 된다.
> **형이 언제든 GitHub 웹에서 이 파일에 한 줄 추가하면, 다음 배치부터 자동 반영된다.**
> 형식: `- 소재 — 다뤄야 할 구체 포인트(수치/조건분기/헷갈림 해소)`

---

## 1. 클렌징·세안
- 아침 세안 vs 저녁 세안 — 목적이 다름. 아침은 밤새 나온 피지·잔여물, 저녁은 선크림·미세먼지. 제품을 2개 쓰는 전략
- 클렌징폼 pH — 약산성(5.5 전후)과 알칼리성의 차이, 순함도 순위, 타입별 추천
- 아침엔 저자극 약산성 / 저녁·운동 후엔 세정력 강한 폼 — 2개 운용법과 각각 언제
- 클렌징 밀크 vs 오일 vs 밤 vs 워터 — 질감·세정력·잔여감 비교, 어떤 상황에 뭘
- 필링젤 — 사용 주기(주 몇 회), 세안 전인지 후인지, 문지르는 시간
- 조합 금지 — 필링젤 + 자극적 클렌저 같이 쓰면 안 되는 이유, 각질제거와 겹치는 날 조정
- 이중세안 필요/불필요 판단 기준, 과세안 신호와 회복

## 2. 자외선 차단
- 무기자차 vs 유기자차 — 원리 차이, 백탁·유분감·자극 비교, 피부타입별 추천
- 재도포 현실적 방법(이미 바른 얼굴 위에), 실내·흐린 날 필요 여부
- SPF/PA 숫자의 실제 의미, 1회 도포량 기준

## 3. 기초 케어
- 세럼/앰플/에센스 농도·목적 구분, 순서와 대기 시간
- 도포법 — 두드림 vs 펴바름, 단계별 사용량(동전 크기·방울)
- 성분 — 레티놀·비타민C·나이아신아마이드·BHA: 시간대, 금지 조합, 입문 농도, 적응기
- 팩 — 시트/워시오프/수면팩 용도, 붙이는 시간 상한, 스킨케어 전후 순서, 주 몇 회
- 각질 제거 주기 — 타입별 차이, 과제거 신호

## 4. 고민별 해결
- 미백·잡티 / 모공 / 여드름(단계별) / 유분·T존 / 다크서클 3종 구분 / 홍조 / 잔주름
- 각 고민마다: 원인 계열 → 우선순위 → 동시에 하면 안 되는 조합 → 병원 가야 하는 기준선

## 5. 헤어·두피·면도
- 샴푸 체류 시간, 물 온도, 헹굼, 트리트먼트 두피 회피
- 드라이 온도·거리, 매일 감아도 되는지 판단
- 면도 전 준비·결 방향·날 교체 주기, 면도 후 즉시 할 것/하면 안 될 것, 인그로운 헤어

## 6. 체취·향
- 데오드란트 종류(스틱/롤온/스프레이)와 바르는 타이밍
- 체취 타입별 향수 계열, 뿌리는 위치·개수, EDT/EDP 농도 선택
- 땀 많은 계절 의류 소재·세탁 온도, 운동복 냄새 잡는 세탁법

## 7. 운동 — 장비·관리
- 스트랩(리프팅 스트랩) — 세척 주기, 세탁 방법, 냄새 나기 시작하면, 교체 시점
- 벨트·글러브·요가매트 — 관리와 수명
- 초보 풀업 밴드 — 저항 단계 고르는 법(체중 대비), 부위별 굵기
- 웜업용 미니밴드·폼롤러 — 용도와 고르는 기준, 가격대별 추천
- 홈트 입문 장비 5 — 우선순위와 살 필요 없는 것

## 8. 운동 — 자세·불균형
- 좌우 불균형 자가진단 — 벽에 등 대기, 사진 촬영, 한 발 서기 등 자가 테스트 방법
- 불균형 유형별 대응 — 라운드숄더 / 거북목 / 골반 틀어짐 / 한쪽 어깨 처짐
- 각 유형마다: 어느 부위가 짧아지고 어느 부위가 약해졌는지 → 벽·수건·밴드로 하는 교정 동작 → 하루 5분 구성
- 웜업 5분 루틴 — 부위별 스트레칭 순서와 각 동작 유지 시간
- ※ 통증이 있으면 자가 교정 대신 전문가 상담을 권할 것

## 9. 운동 — 루틴·회복
- 운동 직후 10분 — 샤워 온도, 세안, 두피, 보습 순서
- 운동 전후 식사·수분 타이밍
- 근육통과 부상 구분 기준

## 10. 생활 습관
- 베갯잇 교체 주기와 대안, 얼굴 만지는 습관 차단법
- 물 마시는 타이밍과 1회량, 수면 자세, 실내 습도
- 각 항목은 반드시 "왜 문제인지 + 오늘부터 뭘 할지" 2단 구성

## 11. 상황·시의성
- 면접 / 데이트 / 소개팅 D-1 / 출근 전 / 여행·출장 파우치 / 군인 PX
- 계절 전환기 루틴 변경, 장마·한파·황사 대응

## 12. 확장 후보 (아직 안 다룬 분야)
- 치아·미소 — 화이트닝 옵션, 칫솔·치실 사용법
- 손·손톱 관리
- 안경·시계·액세서리 고르는 기준
- 신발·가죽 관리
- 목소리·말투
- 사진 잘 나오는 각도·조명
- 식단 — 카페인·음주·당 섭취가 피부에 미치는 경로
- 가격대별 피부과 시술
