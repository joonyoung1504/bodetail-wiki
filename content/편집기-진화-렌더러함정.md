# 편집기(bodetail_editor.html) 진화와 렌더러 함정

> 출처: [[raw/2026-07~08_사지방기간_전체기록]] §3, §4. 원래 3개 탭(릴스 자막편집기/게시물편집기/카테고리A릴스)
> 구조에서 게시물편집기 탭 위주로 계속 개선됨.

## 마무리 카드 버그

카드뉴스 마지막 장이 빈 카드로 나오는 문제. 원인: Claude가 slides 타입을 cover/content 외에 summary·outro·closing 등 제멋대로 지정 → 에디터가 모르는 타입은 렌더 안 됨.

**해결 3단**: ① 프롬프트에 "cover/content 타입만, 마무리는 시스템이 자동 추가" 명시 ② 에디터용 JSON 조립 시 마무리 카드를 항상 자동 추가 ③ 에디터에 타입 정규화 함수(`p_normType`)를 추가해 outro/summary 등을 자동으로 closing/content로 변환하는 방어선.

## 편의 기능 추가

- **↕ Y 일괄 / ↔ W 일괄 / ⬛ 전체 일괄**: 자막 Y좌표를 하나하나 맞추기 번거롭다는 요청 → 기준 자막에서 클릭하면 전체 적용, 이후 개별 조정 가능. 확인창 + 적용 피드백(✔ 적용됨) 포함.
- **⊹ 가운데 고정 ON/OFF** (기본 ON): 자막 박스가 드래그할 때마다 좌우로 흔들리는 문제 해결. 켜져 있으면 세로로만 이동, 좌우 핸들 리사이즈도 대칭 확장. JSON 로드 시 자동 중앙 정렬.
- **자막 스타일 3종**(흰 박스 / 외곽선(배경없음) / 검은 박스) + **📌 고정 헤드라인**(영상 전체 길이로 지속되는 검은박스 자막): 참고 예시(다이어트 콘텐츠 캡처)에서 이식.

## 핵심 함정 — "에디터 CSS만 고치면 미리보기만 예뻐지고 최종 산출물은 그대로"

**이 함정이 두 번 반복됨:**

1. **게시물 레이아웃**: 텍스트 하단 정렬로 렌더러를 개편하면서, 처음엔 파이썬 렌더러만 고쳐서 실효 없었음 — 최종 PNG는 실제로는 **에디터(HTML)에서 나온다**는 걸 뒤늦게 인지. 에디터 + 파이썬 렌더러 양쪽 다 수정해야 함.
2. **릴스 자막 스타일**: 자막 스타일 3종 + 고정 헤드라인 기능은 에디터뿐 아니라 렌더러(`generate_daily_reel.py`)도 같이 고쳐야 실제 mp4에 반영됨. 편집기 CSS만 바꾸면 미리보기만 예뻐지고 최종 영상은 그대로인 함정을 두 번째로 지적받음.

**교훈**: 레이아웃·자막 스타일을 바꿀 땐 에디터와 렌더러(파이썬/mp4 조립기) 둘 다 항상 같이 확인·수정한다. (이 교훈은 콘텐츠 자동화 저장소 쪽 CLAUDE.md의 절대 규칙 1번으로도 등록되어 있음 — 이 위키에는 판단 근거·시행착오 맥락만 기록.)
