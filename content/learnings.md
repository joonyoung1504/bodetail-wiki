# bodetail 성과 학습 규칙 (갱신: 2026-07-26)

## 🎯 검증된 규칙 (반드시 반영)

- **훅/제목 — 숫자 구체화**: 커버에 숫자 포함 필수 ("4가지 차이", "8가지 습관", "7가지 오해", "4곳이 문제다"). 숫자 없는 커버("실루엣은 몸이 만든다", "30분의 루틴")는 저장 유도력이 상대적으로 낮을 가능성 있음 — 단, 수치 미수집으로 강도는 검증 중.
- **훅/제목 — 반전·경고형 서브 카피**: 커버 서브 문구에 "잘못 쓰면", "아직 반도 안 한 것", "다 헛수고" 등 손실 회피 언어 삽입. 독자가 현재 상태가 잘못됐을 수 있다는 긴장감을 유발해 슬라이드 진입률을 높임.
- **주제/섹션 — 실용 지식형 우선**: 스킨케어 정보(레티놀·세럼·피부 구조·기초 순서), 구취·자세 등 즉시 적용 가능한 신체 관리 주제가 콘텐츠 밀도의 핵심. 추상적 동기부여 금지 규칙 유지.
- **구성/슬라이드 — 6~7장 범위 유지**: 전체 10건 중 9건이 6~7장. 8장(day04 향수)은 단독 이탈. 현재 데이터 내에서 6~7장이 운영 표준임을 확인.
- **구성 — 체크리스트(✔) 활용**: day07·day08·day09·day10·day11이 캡션 본문에 ✔ 항목 나열 구조 채택. 스캔 가독성 확보 및 저장 욕구("나중에 확인용") 자극에 유효한 패턴으로 반복 검증됨.
- **캡션 구조 — 3단 고정**: ① 첫 줄 훅(문제 제기 or 반전) → ② ✔ 항목 or 번호 나열(실행 팁) → ③ 저장 유도 문구. "이 카드 저장해두면 루틴 정리할 때 기준이 생겨요"처럼 저장의 실용적 이유를 명시하는 방식 유지.
- **캡션 — 저장 유도 문구 전면 배치**: day01(남자 피부)·day02(세럼 앰플)는 캡션 2~3줄 내 저장 언급. 후반부 배치보다 전반부 노출이 저장 전환에 유리하다는 구조적 근거로 채택.

## 🧪 검증 중 (다음 주 관찰)

- **상황특정형 vs 일반 정보형 저장률 차이**: day08(데이트 30분 전)은 상황특정형, day10(구취 4곳)·day11(기초 4단계)은 일반 정보형 — API 수치 수집 후 비교 필요.
- **숫자 없는 커버의 실제 성과**: day06("실루엣은 몸이 만든다")·day07("자세로 3cm") — 3cm는 숫자이나 커버 주제가 추상적. 도달 대비 저장률 별도 추적 필요.
- **8장 슬라이드(day04 향수) 완독률**: 6~7장 표준 대비 이탈 지점 확인 안 됨. 향수 카테고리 자체의 관심도 변수 포함.
- **섹션 네이밍("오늘의 디테일" 집중) 효과**: 7~8월 게시물 중 "디테일" 섹션 비중이 높음. 섹션명이 저장·팔로우에 미치는 영향 미검증.

## 🗑️ 폐기 (데이터와 모순)

- **캡션 후반 저장 유도 공식**: 기존 규칙의 "훅 → 저장 유도 → 요약" 순서 중 저장 유도를 후반에 배치하는 구조 — 실제 고성과 추정 게시물(day01·day02)에서 저장 유도 문구가 캡션 상단 2~3줄 내 등장. 후반 배치 공식 폐기, 전반 배치로 교체.
