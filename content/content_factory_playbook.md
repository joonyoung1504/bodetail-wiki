## 이 공장의 역할 분담

- **Claude(공장)**: 주제 선정 → 후킹 카피 → 디자인 사양 → 이미지 생성/소싱 → 캡션·해시태그 → 완성 패키지 산출.
- **준영(운영)**: 업로드 → 성과 데이터 API 수집 → GitHub 기록 → 다음 주제 피드백.
- **피드백 루프**: 준영이 "지난 게시물 조회수/공유 Top·Bottom"을 주면, Claude가 다음 주제 선정에 반영.

## 매일 실행 순서 (8 STEP)

### STEP 1 — 주제 선정
- 우리 영토(우선순위): **그루밍·디테일 > 향수 > 손·손톱 디테일 > 그루밍 큐레이션 > 컨디션/무드**.
  (세르칸과 겹치는 스킨케어·피부도 가능하되, 우리는 "디테일·안목" 렌즈로 변환.)
- 후킹 우선순위(voice_guide) 적용: **즉효·디테일형 > 즉시실행형 > 상황특정형 > 시의성형**.
- 시의성 체크: 오늘 날짜/계절/이벤트(면접시즌·환절기·연말 등) 반영.
- 중복 방지: 최근 게시한 주제와 안 겹치게(준영이 최근 목록 주면 참조).
- **P1 제약**: 우리 제품 직접 언급 0. 손·손톱 주제는 월 1회 수준으로 극소수, '제품'이 아니라 '디테일'로.
- 산출: 주제 1개 + 섹션 라벨(WHY/PICK/오늘의 디테일/그 순간/레퍼런스/TREND) + 왜 터질지 1줄.

### STEP 2 — 후킹 카피 (제목)
- voice_guide 헤드라인 공식 7종 중 택1 + 후킹 우선순위 조합.
- **2단 헤드라인**으로: 얇은 보조줄(맥락/시리즈) + 굵은 메인.
- 가능하면 숫자/넘버링 포함("디테일 6", "BEST 5", "上中下").
- 어투: 명사형 단정 / 해요체 / 질문형 중 콘텐츠에 맞게. 반말 직접호명 금지.
- 산출: 메인 헤드라인 + 보조줄 + (영문 임팩트 옵션).

### STEP 3 — 캐러셀 구조 설계
- 슬라이드 수: 보통 5~8장.
- 구성: 커버(아키타입 A/B) → 콘텐츠(C, 넘버링 01~N) → [PICK이면 D/F] → 마무리(E).
- 각 슬라이드의 소제목 + 본문(2~3줄) 작성. 본문은 voice_guide 문장규칙(짧게, 의미단위 줄바꿈).
- 산출: 슬라이드별 텍스트 전체.

### STEP 4 — 이미지 소싱/생성

**소싱 우선순위:**
1. **Pinterest** (감도 최우선) — 무드·감성 맞는 서양풍 실사. 검색어 예시: "dark moody men grooming editorial", "cinematic noir men hands detail".
2. **Pexels / Unsplash / Dreamstime / Craiyon** — 상업 라이선스 명확. 무드 컷 위주.
3. **기타 웹 이미지** — 감도가 맞으면 사용. 저작권은 운영자 판단/책임.
4. **AI 생성(Higgsfield)** — 크레딧 있을 때 오브제·손 클로즈업.
5. **자체 촬영** — 네일샵에서 손·제품 실사.

**후처리(그림자 레이어 — 버전 B 기준, 코드로 고정):**
- `filter: saturate(0.15~0.25) contrast(1.08~1.12) brightness(0.72~0.82)` — 저채도
- 잉크블랙 멀티플라이 오버레이 `rgba(10,8,5,0.45~0.50)`
- 하단 롱 그라데이션 55~60% 커버
- 비네팅 + 미세 그레인
- **어떤 사진이 와도 이 스택을 거치면 우리 톤으로 통일됨.**

**산출:** 슬라이드별 이미지 URL 또는 CSS background-image 세트.

### STEP 5 — 디자인 조립
- DESIGN-bodetail 토큰·컴포넌트로 1080×1440 카드 조립.
- 고정 요소(모든 슬라이드 동일 위치): 좌상단 라벨+헤어라인, 하단 중앙 signature-wordmark, 하단 scrim 그라데이션(35~50% 롱페이드).
- 헤드라인 자유 배치 허용(단조로움 방지), 단 고정 요소는 픽셀 고정.
- 감도 3원칙 중 최소 2개(클로즈업/도형/반복) 충족 확인.
- 산출: 슬라이드별 최종 PNG (또는 Pillow 코드).

### STEP 6 — 캡션 작성
- 세르칸 6단 구조(voice_guide):
  1. (광고X 또는 광고 표기) + 호기심 헤드라인
  2. 공감 도입 2~3줄
  3. 관점 전환 1줄
  4. 넘버링 요약 01~N
  5. bodetail 슬로건 1줄
  6. 인게이지먼트 유도(팔로우/저장/댓글 — 셀프프로모션 아닌 건 OK) @bodetail_official
- **P1 절대 규칙**: 우리 제품 직접 홍보·판매 문구 0.
- 산출: 캡션 전문.

### STEP 7 — 해시태그
- 6~10개, 본문 끝 또는 첫 댓글.
- 구성: 브랜드(#bodetail) + 카테고리(#남자그루밍 #남자향수 #그루밍 #남자자기관리) + 주제별 가변.
- 밈 태그(.zip 등) 금지.
- 산출: 해시태그 세트.

### STEP 8 — 완성 패키지 + 셀프 QA
- 아래 체크리스트 통과 후, 한 세트로 묶어 제공.
- 준영은 이걸 그대로 업로드.

## 완성 패키지 출력 형식 (항상 이 형식으로)

```
■ 오늘의 게시물 — [날짜]
[섹션 라벨] · 주제: ____ · 왜 터질지: ____

▸ 슬라이드 (N장)
  1. [커버] 헤드라인: "____" / 보조줄: "____" / 이미지: [검색어/URL]
  2. [01] 소제목 / 본문 / 이미지: ____
  ...
  N. [마무리] 워드마크 + 태그라인

▸ HTML 파일 (바로 스크린샷 가능)
  → 슬라이드 전환 버튼 포함 600×800px (3:4)
  → 각 슬라이드 스크린샷 → 캐러셀 순서로 업로드

▸ 캡션 (복붙용 전문)

▸ 해시태그 (첫 댓글 or 본문 말미)
```

**스크린샷 업로드 방법 (HTML → Instagram):**
1. HTML 파일을 브라우저로 열기 (크롬 권장)
2. 브라우저 줌 150~200%로 키우면 더 큰 이미지
3. 슬라이드 01부터 마무리까지 각 1장씩 스크린샷 (단축키: Cmd+Shift+4 맥 / Win+Shift+S 윈도우)
4. 슬라이드 영역만 캡처 (컨트롤 바 제외)
5. Instagram 캐러셀 업로드 → 캡션 붙여넣기 → 해시태그 첫 댓글

## 셀프 QA 체크리스트 (제공 전 필수)

- [ ] 우리 제품 직접 홍보 0 (P1)
- [ ] 운영자 얼굴/신원 노출 0, 랜덤 AI 인물 0, 저작권 불명 이미지 0
- [ ] 1080×1440(3:4), 고정요소(라벨·워드마크·그라데이션) 픽셀 고정
- [ ] 감도 3원칙 중 2개 이상
- [ ] 2단 헤드라인 + 가능시 넘버링
- [ ] 골드 면적 5% 이하, 두번째 액센트 컬러 없음
- [ ] 캡션 6단 구조 + 인게이지먼트 유도(셀프프로모션 아님)
- [ ] 해시태그 6~10개, 밈태그 없음
- [ ] 마스코트 확정 시 동일 외형 유지
- [ ] 금칙어("화장"·세일즈어휘·밈) 없음

## 주제 풀 (마르지 않게 — 초기 시드)

그루밍·디테일: 향수 레이어링, 손끝 인상, 면도 후 케어, 디테일이 인상을 가르는 순간, 향 고르는 기준, 손톱 정리(월1).
컨디션·무드: 숙면과 컨디션, 환절기 케어, 첫인상의 과학.
큐레이션(PICK, 타사): 입문 그루밍템, 데일리 캐리 디테일, 향수 입문 5.
시의성: 면접 시즌, 연말 모임, 환절기, 새해 루틴.

> 매번 다른 각도로 변주. 같은 주제도 후킹·슬라이드 구성 바꾸면 새 콘텐츠.

## 자동화 연계 (준영 파트, 참고)

- 이 플레이북의 STEP 1~7 산출물은 결국 `content_calendar.json` 1개 항목으로 정형화 가능.
- 완전 자동화 시: generate.py(이미지+Pillow 텍스트) → publish.py(Meta Graph API) → cron.
- 성과 수집: Meta Graph API로 조회수·공유·저장 → GitHub 기록 → Claude가 다음 주제 선정에 반영(바이럴 주제 우선).
- 현재 단계: 초반은 Claude가 수동으로 STEP 1~8 실행 → 검증되면 코드로 이관.

## Known Gaps

- 마스코트 미확정 → 확정 전까지 오브제·손 클로즈업으로 운영.
- bodetail 슬로건(캡션 5번) 미확정.
- content_calendar.json 90일치 미작성.
- generate.py/publish.py 골격 미작성(전역 후 git 환경에서).
- 성과 피드백 루프의 구체 지표 기준(어떤 수치 이상이면 "바이럴") 미정.
