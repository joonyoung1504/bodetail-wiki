# 콘텐츠 & 수요검증 마스터플랜

## North Star (단 하나의 목표)
전역(9월)까지 "이 제품 팔린다"는 증거를 숫자로 만든다.
대기자 명단 + 릴스 반응 데이터 = 예창패 합격 근거 + 양산 결정 근거.
제품을 더 다듬는 것보다 첫 릴스 1개의 반응이 지금 더 값지다.

> 관련 결정: [[decisions/주요-의사결정]] — "수요 검증 먼저, 양산 나중" / 토리든식 오가닉 전략

---

## 1. 전략 — 왜 손톱부터인가

- 간판(브랜드)은 넓게: "놓치기 쉬운 디테일을 돌본다" (손톱→큐티클→입술→발 확장)
- 첫 콘텐츠는 좁게: "손톱 뜯는 습관"이라는 뾰족한 페인으로 먼저 꽂는다
- 순서 주의: 매거진부터 빌드업 X → 손톱 훅으로 도달 터뜨리고 세계관은 나중에
- 타깃: 메인=20~30대 남성 / 여론·구매결정=여성 → [[brand/타깃-페르소나]]

---

## 2. 페이즈 로드맵

| 페이즈 | 기간 | 핵심 목표 | KPI |
|--------|------|---------|-----|
| **P1** | 1~2개월 | 손톱 훅으로 도달 터뜨리기 | 저장률 4%+, 팔로워 0→500 |
| **P2** | 2~4개월 | 세계관·신뢰 빌드업 ("머물게 한다") | 팔로워 500→1,500, 대기자 폼 오픈 |
| **P3** | 4~6개월 | 수요 검증 ("수치화") | 대기자 폼+샘플 후기, 예창패 발표 자료 |
| **P4** | 출시 후 | 확장 ("손톱→디테일") | 큐티클·강화제 등 인접 제품 |

- 손톱 콘텐츠 비중: P1 90% → P4 40%로 서서히 조정
- EP1~EP4 잠금·리빌 구조 → [[brand/EP1-릴스-시퀀스]]

## 3. 릴스 콘티 5개 (P1용 — 바로 촬영 가능)

### EP1-A 길거리 투표 — "이성 볼 때 신경 쓰이는 곳"
- 목표 반응: 저장·공유 / 형식: 길거리 인터뷰
- 0~3초: "이성 볼 때 의외로 제일 신경 쓰이는 신체부위 1위는?"
- 3~10초: 손톱 vs 겨땀자국 vs 떡진머리 투표 → 손톱 의외 상위
- 반전: "의외로 손톱을 많이 본다. 근데 가장 방치하는 부위"
- CTA: "당신은 손톱 자신 있나요? 댓글로" + 프로필 링크

### EP1-B 비포애프터 타임랩스 — "30일의 변화"
- 목표 반응: 완주·체류 / 형식: 타임랩스
- 0~3초: 거친 손톱 + "30일 뒤, 이 손톱이 어떻게 됐을까?"
- 3~12초: Day1→Day30 타임랩스 (끝까지 봐야 결과)
- CTA: "저장 🔖 / 출시 알림은 프로필"

### EP1-C 창업자 고백 — "저도 손톱 뜯었습니다" ★첫 릴스 추천
- 목표 반응: 댓글·공감 / 형식: 토킹헤드
- 0~3초: "솔직히 고백할게요. 저 20년 동안 손톱 뜯었어요."
- 공감 스토리 + "같은 고민 있는 분? 혼자 아니에요"
- CTA: "'저요' 댓글 / 같이 바꿔봐요"
- ※ 찍기 쉽고 공감 댓글 잘 나옴 — 첫 릴스로 적합

### EP1-D 정보형 — "손톱 뜯는 사람만 아는 것"
- 목표 반응: 저장 / 형식: 정보 리스트
- "손톱 뜯는 사람만 아는 것 3가지" → 공감 자막 연타
- "오래된 습관이지 당신 잘못이 아니에요" (※ "질병·치료" 표현 금지)

### EP1-E 제품 티저 — "곧 나옵니다"
- 목표 반응: 링크클릭·대기자 / 형식: 무드 티저
- 롤온 실루엣 + "남자 손끝을 위한 게 곧 나옵니다"
- CTA: "출시 알림 받기 → 프로필 링크(얼리버드)"

> 변수 실험 매트릭스(훅 유형·포맷·길이·CTA) 상세 → [[brand/EP1-릴스-시퀀스]]

## 4. 반응유도 설계

좋아요가 아닌 **저장·공유·댓글·완주**를 노린다.

| 목표 반응 | 적합한 콘티 |
|---------|----------|
| 저장·공유 | 길거리 투표 (EP1-A), 정보형 (EP1-D) |
| 댓글·공감 | 창업자 고백 (EP1-C) |
| 완주·체류 | 비포애프터 타임랩스 (EP1-B) |
| 링크클릭 | 제품 티저 (EP1-E) |

각 릴스를 hook / format / topic으로 태깅해 발행 → 뭐가 터지는지 측정 → 반복.
인플루언서 협업 검토 → [[brand/콘텐츠-인플루언서]]

## 5. 수요검증 — 대기자 명단 (스모크 테스트)

- **하면 안 됨**: 가짜 결제 유도 후 "배송 지연" → 기만, 절대 금지
- **해야 함**: "출시 알림 받기" 대기자 명단. 대기자 수 = 수요 증거
- 구글폼 구성: 제품 소개 + 알림 신청 + 선호 조사(30일 1병/90일 3병) + 가격 반응(2.5만원 의향 5점)
- 릴스 CTA → 폼 연결 → **대기자 수가 예창패 근거**
- 상표 출원 시점 참고 → [[decisions/상표-임상-예창패]]

---

## 6. 측정 (3일째 숫자만)

- 저장률(목표 4%+) / 공유·DM / 완주율 / 댓글 / 프로필방문·링크클릭 / 팔로워
- 이긴 주제·형식을 변형해 반복. **한 번에 하나만 바꿔 비교**
- 1,000명 넘으면 메타 API 자동화 → [[decisions/콘텐츠-볼트-운영]]

---

## 7. 주간 리듬

| 시기 | 목표 |
|------|------|
| 6월 | 계정 개설 + 첫 3개 발행 |
| 7월 | 주 2~3개 발행 |
| 8월 | 반응 데이터 기반 조정 + 대기자 폼 오픈 |
| 9월 | 데이터 정리 → 예창패 자료화 |

- 군 복무 중 → 주 2~3개면 충분 (3개월 = 30개 + 데이터)
- 촬영 팁: **외박 때 여러 개 몰아 촬영** → 평일에 하나씩 발행

---

## 8. 오늘 할 일

1. 인스타 계정 개설 (`@bodetail`, 소개: "손끝 디테일이 첫인상을 바꾼다·곧 출시") — 10분
2. 비즈니스 계정 전환 — 2분
3. 손톱 비포 촬영 (본인 또는 동의한 살롱 고객) — 15분
4. 첫 릴스 1개 발행 (추천: EP1-C 창업자 고백) — 이번 주
5. 대기자 구글폼 만들기 — 이번 주~다음 주
6. 발행 3일째 숫자 기록 → 위키에 추적

---

## 핵심 한 줄
준영의 강점은 "만들기"(위키·의뢰서·시스템 다 훌륭). 근데 "올리기"를 아직 한 번도 안 했다.
그게 진짜 시험. 오늘 계정 만들고 손톱 한 장 찍는 것 = 지금까지 만든 모든 것보다 중요.
