# bodetail-vault — LLM 위키

보디테일 브랜드 런칭을 위한 지식 베이스. LLM과 협업해 제품·브랜드·시장·운영 정보를 관리한다.

---

## 폴더 구조

```
bodetail-vault/
├── product/        제품 처방·용기·성분 결정
├── brand/          브랜드 톤·로고·페르소나
├── market/         경쟁사·시장 분석
├── ops/            OEM 업체·회신·일정
├── decisions/      의사결정 기록
├── raw/            정리 전 원본 자료
├── WIKI-RULES.md   LLM 위키 운영 규칙
└── README.md       이 파일
```

---

## 빠른 시작

### 새 정보 추가
1. 원본 자료(이메일·메모·회의록)는 `raw/`에 먼저 저장한다.
2. LLM에게 `/query raw/ 폴더 최근 노트 정리해줘` 라고 하면 적절한 폴더로 분류해준다.

### 질문하기
```
/query [질문]
```
위키 전체를 컨텍스트로 참조해 답변한다.

예시:
```
/query 현재 OEM 협의 진행 상황은?
/query 브랜드 타깃 페르소나와 맞는 경쟁사는 어디야?
/query 지금까지 확정된 의사결정 목록을 시간순으로 보여줘.
```

### 위키 정리
```
/lint
```
frontmatter 누락, 끊어진 링크, 오래된 노트 등을 일괄 점검한다.

---

## Frontmatter 형식

모든 노트는 아래 형식의 frontmatter로 시작한다.

```yaml
---
summary: "한 줄 요약"
tags: [폴더명, 추가태그]
created: YYYY-MM-DD
updated: YYYY-MM-DD
---
```

자세한 규칙은 [[WIKI-RULES]] 참고.

---

## 노트 간 연결

- `[[노트명]]` 으로 관련 노트를 연결한다.
- 각 노트 하단 `## 관련 노트` 섹션에 역참조를 명시한다.
- 아직 없는 노트는 `[[미작성/노트명]]` 으로 표기한다.

---

## 운영 원칙 요약

| 규칙 | 내용 |
|------|------|
| frontmatter | 모든 노트에 summary·tags·created·updated 필수 |
| 원본 보존 | 가공 전 자료는 항상 `raw/`에 원본 저장 |
| 결정 기록 | 무엇을·왜·언제 결정했는지 `decisions/`에 기록 |
| 링크 연결 | 관련 노트는 반드시 `[[링크]]`로 연결 |
| 주기 정리 | 월 1회 `/lint` 실행 권장 |
